# DOLBUTO

블록으로 넓은 세계를 만들고 탐험하는 샌드박스 게임을 개발하고 있습니다.

현재 소스는 **지표 Y=192의 임시 돌 평지, 걷기·자유 비행과 블록 파괴·놓기**를 제공합니다. 세계는 동서·남북 각각 131,072블록 크기로 이어져 있어 끝을 넘으면 반대편으로 돌아옵니다. 플레이어는 가로·깊이 0.7블록, 높이 1.75블록의 흰색 직육면체이며 같은 크기로 지형과 충돌합니다. 물은 한 칸의 양을 256단위로 계산하며, 초당 20번 아래와 옆으로 흐릅니다. 수면은 16단계로 표시합니다.

용암은 핫바 7번으로 설치합니다. 전체 물리 계산은 20TPS를 유지하며 용암은 그 안에서 20틱마다, 즉 초당 한 번 움직입니다. 이동량은 갱신당 아래 최대 256·수평 총 16입니다. 용암 표면 높이는 출렁이지 않고 텍스처 무늬만 천천히 움직이며 빛을 냅니다. 현재 물과 용암은 서로 섞이지 않고, 접촉 반응이나 용암 피해는 없습니다.

물은 아래로 한 틱에 최대 256, 수평 4방향으로는 한 칸에서 총 16까지 이동하며 총량을 보존합니다. 수위 차이가 작으면 이동량도 줄어들고, 내부량 차이가 1이면 멈춥니다. 아직 로딩되지 않은 곳으로는 흐르지 않습니다. 물을 없애지 않도록 현재 물이 있는 칸에는 고체를 설치할 수 없습니다. 물 이동과 블록 편집은 이번 플레이 세션 안에서 유지되며, 월드 재생성이나 새 월드 진입 때 초기화됩니다.

현재 임시 평지는 돌로만 생성하며 자연 물은 없습니다. 물·잔디·흙·모래 등은 핫바에서 직접 설치할 수 있습니다.

물 표현은 깊이에 따른 색·투명도, 잔물결, 하늘·구름·화면 공간 반사(SSR), 굴절, 물가 거품과 수중 빛 무늬를 제공합니다. 공기에 노출된 가득 찬 물은 높이 7/8로 표현하고, 부분적으로 찬 물은 16단계로 낮아집니다. 아주 적은 물도 최소 한 단계로 표시합니다. 한 단계 차이의 이웃 수면은 모서리 높이를 공유해 완만하게 연결하며, 큰 낙차와 벽 경계는 유지합니다. 물속 지형의 빛 무늬는 물 안팎에서 볼 수 있습니다. 수중에서는 가까운 풍경을 선명하게 유지하고 먼 풍경에 청록색 안개를 적용하며, 수면 너머는 굴절되어 보이며 수중에서도 수면 반사가 나타납니다. 물결·색·투명도·반사·거품은 Complementary Unbound를 바탕으로 표현합니다. 물 반사는 화면 가로·세로의 75% 해상도로 계산합니다. 반사 탐색 거리는 렌더 거리에 맞춰 최대 1,024블록까지 조절합니다. Complementary Unbound 방식의 입체 구름, 방향·구름 그림자, 하늘과 노을, 태양·보름달·밤하늘의 별, 안개·빛줄기, 블룸도 추가했습니다. 그래픽 효과는 옵션에서 개별적으로 조절할 수 있습니다.

최신 배포 빌드는 `out/DOLBUTO/DOLBUTO.exe`에 있습니다.

## 실행

Windows x64용 빌드 폴더에서 `DOLBUTO.exe`를 실행하세요. 같은 폴더의 `assets`와 `shaders`도 필요합니다. Vulkan 1.4를 지원하는 그래픽 드라이버가 필요하며, 공식 최소 하드웨어 사양은 아직 정하지 않았습니다.

시작 화면 중앙에 위에서 아래로 다음 버튼이 표시됩니다.

- **싱글플레이:** 월드 선택 화면 없이 바로 입장.
- **옵션:** 넓은 설정 창의 화면·물·구름·그림자·대기·빛 메뉴에서 조절. 인게임 설정과 같은 값을 사용하며, **돌아가기 / Esc**로 시작 화면에 복귀합니다.
- **게임 종료:** 프로그램 종료. Esc로는 게임이 종료되지 않습니다.

공통 단축키:

- **F3:** 좌상단 진단 텍스트 표시·숨김. 창과 배경 없이 얇은 검은 외곽선의 굵은 흰 글자로 FPS·프레임 시간·좌표·청크·메모리·게임 날짜·시각·일차·조명 갱신 상태 등을 표시하며, 이동과 게임 조작은 계속됩니다. 기본은 숨김입니다.
- **F3 방향:** 플레이어의 수평 시선을 북쪽(−Z)·남쪽(+Z)·동쪽(+X)·서쪽(−X)으로 표시합니다. 각 방향은 90° 구간이며, 앞 3인칭에서도 플레이어 기준을 유지합니다.
- **F3 기후 단계:** 현재 위치의 온도·강수량 원래 값과 단계 이름(1~9)을 표시합니다. 두 값 모두 −1~+1을 같은 폭으로 9등분하며, 범위를 벗어난 값은 양 끝 단계로 표시합니다. 온도는 극한~극열, 강수량은 극건조~극습윤입니다.
- **F3 지형:** 임시 돌 평지와 지표 높이를 표시합니다. 기존 바다·강·육지 분류는 제거했습니다.
- **F8:** 인게임 월드·기후 설정창 열기·닫기. 기본은 숨김이며, 열면 마우스로 설정을 편집하고 이동·블록 편집은 멈춥니다.
- **F2:** 현재 화면과 표시 중인 UI를 PNG로 저장. 실행 파일 옆 `screenshots` 폴더에 날짜·시간 이름으로 저장하며 화면에 결과를 알립니다.
- **F11:** 전체화면·창 모드 전환.

F3 우상단의 **RAM**은 게임 프로세스가 실제 RAM에 올려 둔 메모리(공유 페이지 포함), **전용 커밋**은 게임이 확보한 전용 메모리입니다. 두 수치는 합산하지 않으며 GPU 메모리와 별도로 GiB 단위로 표시하고 1초마다 갱신합니다.

**싱글플레이**로 입장한 뒤에는 다음과 같이 조작합니다.

- **WASD / 마우스:** 수평 이동 / 시점 회전. 위아래를 바라봐도 WASD로는 높이가 변하지 않습니다.
- **Z 길게 누르기:** 망원경처럼 확대합니다. 누르는 동안 시야각과 마우스 감도가 평소의 1/4로 줄고, 떼면 복원됩니다. 1·3인칭 모두 지원하며 렌더 거리는 그대로입니다. 메뉴·콘솔·F8 편집 중에는 작동하지 않습니다.
- **Space 두 번(0.3초 이내):** 걷기 ↔ 플라이 전환. 시작은 걷기 모드입니다.
- **Enter:** 인게임 명령 콘솔 열기. 입력창은 화면 아래에서 약 1/3 높이에 표시됩니다. Enter로 실행하고, Esc 또는 빈 입력에서 Enter로 닫습니다. ↑/↓로 이전 명령을 찾을 수 있으며 콘솔에서는 이동·블록 조작이 차단됩니다.
- **콘솔 명령:** `/help` 도움말, `/time 09:00` 현재 날짜의 시각 변경, `/tp 100 250 32768` 발 좌표 이동, `/gamemode walk` 걷기, `/gamemode fly` 비행. `/time`, `/tp`, `/gamemode`만 입력하면 현재 값을 보여 줍니다. 이동 좌표는 소수를 지원하고 X/Z는 월드 경계에서 순환합니다. Y는 0~8192이며 이동할 위치의 빈 공간을 자동으로 찾지는 않습니다.
- **Space / Ctrl:** 플라이에서 상승 / 하강. 걷기에서는 Space로 점프하고, 누르고 있으면 착지할 때마다 다시 점프합니다. Ctrl로 하강하지 않습니다. **Shift:** 빠르게 이동.
- **좌클릭 / 우클릭:** 바라보는 블록 파괴 / 바라보는 면에 블록 놓기. 모든 시점에서 플레이어 눈높이와 바라보는 방향을 기준으로 사거리는 6블록이며 대상에 테두리가 표시됩니다. 클릭 한 번당 한 블록을 편집합니다.
- **1~9·0 / 마우스 휠:** 중앙 하단의 10칸 핫바를 선택합니다. 왼쪽부터 1~9·0에 대응하며, 1~9칸은 흙 / 잔디 / 돌 / 모래 / 흰색 발광 블록 / 물 / 용암 / 얼음 / 눈이고 0번은 빈 슬롯입니다. 빈 슬롯에서는 블록을 놓지 않습니다. 선택된 칸에는 흰색 선택 테두리가 표시됩니다. 휠은 양 끝에서 순환하며 옵션·F8을 조작할 때는 선택을 바꾸지 않습니다.
- **8번 얼음 / 9번 눈:** 얼음은 일반 블록처럼 설치합니다. 눈은 우클릭마다 한 겹(1/16블록)씩 쌓이고, 덜 찬 눈에 계속 추가할 수 있습니다. 16겹으로 꽉 찬 눈의 윗면에 놓으면 위 칸에 새 한 겹이 생깁니다. 새 눈은 높이 1블록인 고체 위에 놓을 수 있으며, 좌클릭하면 한 겹씩 제거합니다.
- **6번 물 / 7번 용암 선택 후 우클릭:** 바라보는 고체 면에 인접한 칸을 선택한 유체로 가득 채웁니다. 같은 종류의 유체는 보충할 수 있지만 물과 용암을 서로 덮어쓸 수 없습니다. 한 번 채워진 뒤 흐르는 유한한 양이며, 계속 공급하는 수원이 아닙니다.
- **`[` / `]` 길게 누르기:** 시간을 뒤로 / 앞으로 이동합니다. 현실 1초당 게임 1시간이며 둘 다 누르면 시간이 멈춥니다. 옵션·F8에서는 작동하지 않고, 게임으로 돌아오면 키를 놓았다가 다시 눌러야 합니다.
- **F5:** 1인칭 → 뒤 3인칭 → 앞 3인칭 → 1인칭 순환. 3인칭은 플레이어 눈높이를 기준으로 6블록 떨어지며, 벽이 있으면 가까워집니다.
- **F4:** LOD 단계 보기 켜기·끄기. 실제 청크는 회색, 먼 지형과 물은 표시 중인 LOD 단계별 색으로 나타납니다. 검은 선은 LOD 타일 경계이며 우측 범례에서 색과 기둥 크기를 확인할 수 있습니다. 다시 누르면 일반 화면으로 돌아옵니다.
- **Esc:** 게임 화면이 어두워지며 일시정지 메뉴를 엽니다. **옵션**에서 넓은 설정 창을 열 수 있습니다. 설정 창에서 Esc는 일시정지 메뉴로, 다시 Esc 또는 **게임으로 돌아가기**는 게임으로 복귀합니다. 메뉴가 열린 동안 이동과 블록 편집은 멈춥니다.
- **- / =:** 구름 양을 1%씩 줄이거나 늘립니다(0~100%). 길게 누르면 연속 조절하며 값은 저장됩니다. 메뉴나 F8 편집 중에는 작동하지 않습니다.
- **옵션의 렌더 거리:** 슬라이더나 −/+ 버튼으로 **1~64컬럼** 범위를 즉시 변경합니다. 최초 기본값은 12컬럼이며 시작 메뉴의 옵션과 같은 값을 사용합니다. 변경한 거리는 자동 저장되어 다음 실행에도 유지됩니다.
- **옵션의 먼 지형 (LOD):** 기본 켜짐, 반경 **128컬럼(2,048블록)**. 16~256컬럼 사이에서 조절합니다. 가까운 실제 청크를 우선 로딩한 뒤, 가만히 있어도 먼 곳을 가까운 순서로 채웁니다. 첫 생성에는 시간이 걸리며 한 번 만든 LOD는 이번 실행 동안만 보관합니다. F8 재생성 또는 종료 시 폐기됩니다. 가까이 오면 실제 청크로 교체하며 Z 확대는 LOD 상세도를 바꾸지 않습니다. 원거리 물도 지형·하늘·구름 반사를 사용하며 물 그래픽 옵션을 따릅니다. 원거리 얼음은 간략한 표현을 사용합니다.
- **옵션의 수직 시야각:** **30~110°**, 기본 75°. 슬라이더 또는 숫자로 조절하며 1·3인칭에 함께 적용됩니다.
- **옵션의 걷기 화면 흔들림:** 기본 켜짐입니다. 걷거나 달릴 때 발걸음에 맞춰 화면이 움직이며, 공중에서는 잦아듭니다. 끄면 흔들림이 사라지고 선택은 자동 저장됩니다.
- **옵션의 최대 FPS:** **30~500 FPS** 또는 **무제한**(기본). 무제한을 해제하면 슬라이더와 숫자 입력을 사용할 수 있습니다. 숫자는 Enter 또는 다른 곳을 클릭하면 적용됩니다.
- **옵션의 VSync:** 기본은 꺼짐입니다. 켜면 모니터에 동기화하고 FPS 조절을 비활성화합니다. 끄면 이전 FPS 제한을 복원합니다. 세 옵션 모두 자동 저장되며 게임 물리 속도는 20 TPS로 유지됩니다.
- **옵션의 물 표현:** 깊이·잔물결·반사·굴절·물가 거품·수중 빛 무늬·수중 색감·안개를 각각 켜고 끕니다. 전체 효과를 끄면 수면 위는 기본 반투명 물, 수중은 왜곡 없는 시야로 돌아가며 수면 높이 7/8은 유지됩니다. 수면 위 굴절과 물가 거품에는 깊이 표현이 필요합니다. 빛 무늬와 수중 안개는 깊이 옵션과 독립적입니다. 굴절은 고급 물 효과·굴절·잔물결을 켜면 적용됩니다. SSR이 찾지 못한 반사는 하늘·구름으로 이어집니다.
- **옵션의 구름·그림자·대기·빛:** 입체 구름·구름 그림자·방향 그림자·하늘과 노을·안개·빛줄기·블룸을 각각 켜고 끕니다. 새 효과는 모두 기본 켜짐이며 이전에 저장한 선택은 유지됩니다. 구름 그림자는 구름, 빛줄기는 방향 그림자를 켰을 때 사용할 수 있습니다. 비활성 항목의 선택값은 보존됩니다.
- **각 그래픽 메뉴의 세부 조정:** 그림자 거리와 품질, 구름·빛줄기 품질, 구름 높이·양·이동 속도, 블룸 강도를 슬라이더와 숫자로 조절합니다. 품질은 1 낮음 / 2 보통 / 3 높음입니다. 그림자 기본값은 거리192블록·2048×2048이며, 카메라 근처에 해상도를 집중합니다. 품질별 해상도는1024/2048/4096이고 매 프레임 갱신합니다. 대기·빛 메뉴에서 TAA를 켜면 화면과 그림자의 깜빡임을 완화합니다. 불러온 지형에만 그림자가 생깁니다. 효과가 무거우면 품질을 낮추거나 개별 효과를 끌 수 있습니다.
- **옵션의 시작 화면으로:** 시작 메뉴에 복귀합니다. 같은 실행 중 다시 입장하면 위치와 블록 변경을 유지합니다. 멀리 갔다 돌아와도 변경한 블록이 유지됩니다.

시작 시점은 1인칭이며 F5로 몸체를 볼 수 있습니다. 두 이동 모드 모두 고체 블록에 닿으면 멈춥니다. 아직 로딩되지 않은 지형으로의 이동도 막습니다. 걷기에는 중력과 지면 점프가 적용됩니다. 걷기는 가속과 감속을 거쳐 평지에서 초당 약 4.32블록, Shift 달리기는 약 5.61블록에 도달합니다. 점프 높이는 약 1.25블록이며, 공중에서는 관성이 유지되고 방향 입력이 지상보다 약하게 작용합니다. 달리면서 점프하면 바라보는 수평 방향으로 추진력이 더해집니다. 물속에서도 중력이 적용되며 수영은 아직 없습니다. 플레이어 몸과 겹치는 곳에는 고체 블록을 놓을 수 없습니다. 물은 플레이어와 겹쳐도 설치할 수 있습니다. 일반 1인칭에서는 몸 안쪽 면을 그리지 않아 몸체가 시야를 가리지 않습니다. 월드는 파일로 저장하지 않습니다. `--world --seed 1337 --render-distance 12`로 실행하면 지정한 시드와 청크 컬럼 반경으로 바로 입장합니다.

새 지형은 플레이어 주변의 가까운 컬럼부터 채워집니다. 이동하면 대기 순서도 갱신하며, 먼 컬럼이 먼저 준비돼도 가까운 빈 컬럼이 채워진 뒤 나타납니다. 가까운 지형이 복잡하면 외곽의 등장이 잠시 늦어질 수 있습니다. 각 컬럼은 세로 전체가 준비된 후 함께 나타납니다.

그래픽 섹션의 모든 설정은 실행 파일 옆 `settings.json`에 저장됩니다. `--render-distance`를 지정하면 해당 실행에서는 그 값이 우선하며, 옵션에서 직접 바꾸면 변경값이 저장됩니다.

**F3**는 좌상단 맨 위에 FPS·프레임 시간을 표시하고 그 아래에 위치·시간·노이즈·지형 계산값을 표시합니다. GPU·메모리·청크·생성 시간은 우상단에 표시합니다. 노이즈 값은 현재 월드 설정과 플레이어 위치 기준으로 초당 10회 갱신하며, 4블록 격자 보간 전의 값이라 실제 블록 표면 높이와 다를 수 있습니다. 좁은 창에서는 두 영역을 위아래로 배치합니다. 좌하단 조작 설명 박스는 표시하지 않습니다.

## 빛과 시간

하늘에서 들어오는 빛은 불투명 블록에 막히고, 물속이나 동굴 안으로 퍼질수록 약해집니다. 흰색 발광 블록은 주변을 밝히며, 설치하거나 부수면 블록 모양을 우선 갱신하고 주변 조명을 비동기로 갱신합니다. 발광 블록 자체는 항상 흰색으로 보입니다.

낮은 **06:00~20:00**, 나머지는 밤입니다. 햇빛은 **05:00~08:00**에 밝아지고 **08:00~18:00**에 최대 밝기를 유지하며, **18:00~21:00**에 어두워지고 **21:00~다음 날 05:00**에 최소 밝기를 유지합니다.

새 월드는 **0년 1월 1일 오전 9시, 1일차(누적 10,800틱)**에 시작합니다. 1년은 365일이고 윤년은 없으며, 2월은 항상 28일입니다. 게임 속 하루는 현실 24분(28,800틱), 게임 1시간은 현실 1분입니다. F3에서 날짜·시각·일차와 누적 틱을 확인할 수 있습니다. `[`·`]`로 시간을 조절하면 날짜도 함께 바뀌며, 0년 1월 1일 00:00 이전으로는 돌아가지 않습니다. 옵션·F8·시작 메뉴에서는 시간이 멈추고, 지형 재생성은 현재 날짜와 시각을 유지합니다.

첫 스폰은 중간 위도대의 마른 땅 위입니다. Z는 28,672 이상 36,864 미만 또는 94,208 이상 102,400 미만에서, X는 월드 전체 범위에서 무작위로 선택합니다. 발밑 지지와 머리 위 공간을 확인한 뒤 걷기 모드로 배치하며, 지형 시드와 생성 규칙은 바꾸지 않습니다.

## 임시 지형과 기후 설정

새 지형 생성기를 준비하기 위해 기존 지형 노이즈·스플라인·입체 밀도 계산을 제거했습니다. 현재는 **Y=0~191이 돌, Y=192~511이 공기**인 평지입니다. 자연 생성 물은 없으며, 핫바에서 물을 설치하면 기존 유체 규칙으로 흐릅니다. 월드 크기·순환 경계·청크 로딩·조명·LOD는 유지됩니다.

**F8**에서 시드·온도·강수량과 기후용 공유 Shift를 편집합니다. 두 기후 값은 평지 높이나 재질에 영향을 주지 않습니다. 온도는 Z=65536에서 따뜻하고 Z=0/131072에서 차가운 위도 띠이며, 강수량은 X/Z 양쪽으로 이어집니다. 값은 섭씨나 실제 강수량 단위가 아닌 지수입니다.

별도 **기후 미리보기** 창에서 전체 월드 또는 지정 범위의 지도를 생성할 수 있습니다. 온도는 파랑→빨강, 강수량은 갈색→파랑입니다. 범위·해상도·랜덤 시드·랜덤 위치·워핑 전 보기를 조절하고, 이미지 위에 마우스를 올려 표본값을 확인하세요.

- **재생성:** 편집한 설정을 현재 월드에 적용합니다. 설치·파괴한 블록과 유체를 초기화하고 플레이어 위치·시점·날짜·시각은 유지합니다.
- **기본값 저장:** 실행 파일 옆 `worldgen.json`에 설정을 저장합니다. 다음 실행부터 사용하며 현재 월드는 자동으로 재생성하지 않습니다.
- **확정 파일 불러오기:** 웹 편집기에서 확정한 설정을 초안에 불러옵니다. 월드 적용은 재생성을 눌러야 합니다.

## 게임 없이 기후 편집

루트의 **`editor.bat`** 또는 배포 폴더의 **`worldgen_editor.exe`**를 실행하면 로컬 브라우저 편집기가 열립니다. 게임 실행이나 인터넷 연결은 필요하지 않습니다. 실행 파일 옆 `assets` 폴더는 유지하세요.

왼쪽에서 온도·강수량·기후 공유 Shift를 편집하고, 오른쪽에서 지도 종류·범위·해상도를 고른 뒤 **미리보기 생성**을 누르세요. 전체 월드·랜덤 영역·워핑 전 보기·PNG 저장을 지원하며 이미지에 마우스를 올리면 표본 좌표와 값을 보여 줍니다. **설정 JSON**에서 직접 편집·가져오기·내보내기도 가능합니다.

- **작업 저장 / 작업 불러오기:** 실행 파일 옆 `worldgen.editor.json`에 기후 작업을 보관하고 불러옵니다. 보로노이 설정과 마스터 시드를 같은 파일에 저장하며, 다음 편집기 실행 때 마지막 작업을 자동으로 불러옵니다. 기후와 보로노이의 저장 버튼은 각 화면의 편집값과 공통 시드를 저장합니다. 다른 화면에서 아직 저장하지 않은 편집값은 그 화면에서 저장하세요. 게임 기본값은 바뀌지 않습니다.
- **게임 규칙으로 확정:** `worldgen.json`을 갱신합니다. 이전 파일은 `worldgen-backups`에 백업합니다.
- **확정 불러오기:** 마지막으로 확정한 규칙을 불러옵니다.
- **편집기 종료:** 로컬 편집기 프로그램을 종료합니다. 브라우저 탭만 닫으면 프로그램은 계속 실행됩니다.

기존 지형 편집·스플라인·Minecraft 원본 비교 화면은 제거했습니다. 이전 설정 파일은 자동으로 덮어쓰지 않습니다. 기존 설정의 기후·워핑 조절값은 읽지만 개별 시드 오프셋은 사용하지 않고, 모든 분포를 마스터 시드에서 만듭니다. 따라서 이전 버전과 기후 무늬가 달라집니다. 직접 저장하면 새 형식으로 저장합니다. 블록 편집 자체는 저장하지 않습니다.

## 보로노이 실험

웹 편집기 상단의 **보로노이 실험 ↗**을 누르면 별도 탭이 열립니다. 시드·기준 셀 크기·점 배치의 불규칙성과 경계 워핑을 조절해 셀 모양을 확인할 수 있습니다. 순환을 유지하기 위해 실제 셀 간격은 월드 크기를 정수로 나눈 값으로 조정하며 화면에 표시합니다.

- **대륙·섬·바다:** 초록은 대륙, 연두는 섬, 밝은 파랑은 군도 바다, 짙은 파랑은 외해입니다. 큰 셀 생성점의 분포 값으로 대륙을 정하고, 남은 바다 중 군도 구역을 골라 작은 셀로 섬을 배치합니다.
- **대륙 크기 / 육지 판정 기준:** 대륙 무리의 규모와 판정 기준을 조절합니다. 기준을 낮추면 대륙이 늘어납니다. 대륙 크기는 셀 자체의 크기를 바꾸지 않습니다.
- **군도·작은 셀:** 군도 구역 크기·판정 기준, 작은 셀 분할 배수, 섬 무리 크기·판정 기준과 가장자리 감쇄 폭을 조절합니다. 기본 큰 셀 간격은 4,096블록, 분할은 가로·세로 각각 4배이므로 군도 안의 작은 셀 간격은 1,024블록입니다. 인접 군도 구역은 작은 셀을 공유합니다. 감쇄는 군도와 대륙·외해 사이에서만 섬을 줄입니다.
- **마스터 시드 / 전체 시드 랜덤:** 셀 배치·대륙·군도·섬·워핑·기후를 하나의 시드로 제어합니다. 열린 기후 편집기와 시드가 동기화됩니다. 기후의 게임 기본값으로 쓰려면 기후 편집기에서 직접 확정 저장하세요.
- **셀별 육지 분포 값:** 생성점에서 읽은 값을 −1 검정~+1 흰색으로 표시합니다. 판정 기준보다 높으면 육지, 같거나 낮으면 바다입니다. 마우스를 올리면 원시 값과 분류를 확인할 수 있습니다.
- **셀 색상 / 경계만 / 생성점까지 거리:** 기존 셀 모양도 확인할 수 있습니다. 셀 색상은 ID 구분용이고, 워핑을 끄면 생성점도 표시할 수 있습니다.
- **확대·이동:** 휠로 확대하고 드래그로 이동합니다. 클릭한 셀은 강조되며, 마우스를 올리면 좌표·셀 ID·분포 값·분류를 보여 줍니다.
- **동서 경계 / 남북 경계:** 월드 양 끝이 이어지는 구역을 봅니다. 음수 좌표도 반대편으로 이어집니다.
- **설정 저장 / 마지막 저장 불러오기:** 셀·대륙·군도·워핑·시드와 지도 범위·해상도·표시 방식을 보관하고 복원합니다. 다음 실행 때 자동으로 불러오며, 위쪽에 저장 여부와 파일 위치를 표시합니다. 변경 후 저장하지 않고 탭을 닫으면 확인 메시지가 나옵니다.
- **실험 JSON 내보내기·불러오기 / 지도 PNG 저장:** 별도 파일로도 보관할 수 있습니다. 가져온 JSON을 다음 실행에도 쓰려면 설정 저장을 누르세요.

전체 대륙·군도·외해의 **큰 셀 개수**와 현재 화면의 표본으로 추정한 **육지·섬 면적 비율**을 따로 표시합니다. 판정 기준은 면적 비율 자체가 아닙니다. 기본 대륙 크기는 32,768블록·판정 기준은 0이며, 실제 높이와 해변·절벽은 아직 정하지 않습니다. 이전 실험 JSON도 읽지만 별도 육지 시드는 무시하고 마스터 시드로 전환하므로 예전 배치와 달라집니다.

보로노이의 셀·대륙·군도 설정은 **편집기 전용**이며 게임의 돌 평지에는 적용되지 않고 `worldgen.json`에도 저장하지 않습니다. 마스터 시드는 기후와 공유합니다. 높은 워핑 강도에서는 같은 셀이 여러 조각으로 보일 수 있고, 넓은 범위에서는 작은 경계가 표본 사이에 생략될 수 있습니다.

기존 `worldgen.draft.json`은 새 작업 파일이 없을 때 기후 초안으로 읽습니다. 새 작업 저장을 눌러도 기존 초안과 게임용 확정 파일은 덮어쓰지 않습니다. 다른 창에서 같은 설정을 먼저 저장한 경우 충돌을 알리며, 현재 작업을 JSON으로 내보낸 뒤 마지막 저장을 불러올 수 있습니다.

## 소스에서 실행

Windows SDK 및 C++ 빌드 도구(Visual Studio의 **C++를 사용한 데스크톱 개발** 구성), Vulkan SDK, PowerShell 7을 준비하세요. 프로젝트 루트에서 다음을 실행합니다.

```powershell
./tools/setup.ps1
./tools/build.ps1 -Preset release
./tools/run.ps1 -Preset release
```

첫 준비 과정에는 인터넷 연결이 필요합니다. 결과는 `build/release/bin`에 생성됩니다.
