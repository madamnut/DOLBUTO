# DOLBUTO

DOLBUTO는 C++와 Vulkan으로 개발 중인 3D 생존 샌드박스 게임입니다.

플레이어는 끝없이 생성되는 블록 세계를 탐험하고, 야생에서 자원을 모으고, 원시적인 도구와 장비를 제작하며 생존해야 합니다.

현재 DOLBUTO는 개발 버전(DEV)입니다.

## 조작법

| 키 | 동작 |
| --- | --- |
| W / A / S / D | 이동 |
| Space | 점프 / 비행 상승 |
| Shift | 웅크리기 / 비행 하강 / 수중 하강 |
| Ctrl | 달리기 |
| Z | 엎드리기 |
| 좌클릭 | 블록 파괴 |
| 우클릭 | 상호작용 / 사용 / 설치 |
| F | 드랍 아이템 줍기 |
| Q | 선택한 아이템 버리기 |
| Ctrl + Q | 선택한 슬롯의 아이템 전부 버리기 |
| R | 선택한 슬롯과 왼손 슬롯 교환 |
| E | 인벤토리 |
| F1 | HUD 표시 전환 |
| F2 | 스크린샷 |
| F3 | 디버그 텍스트 |
| F4 | 와이어프레임 |
| F5 | 시점 전환 |
| F6 | 기후 오버레이 전환 |
| F11 | 전체화면 전환 |
| Esc | 일시정지 / UI 닫기 |
