# 2026-05-10

## Work Log
- Changed dropped-item spawn offset, initial velocity, airborne rotation, and spin from coordinate-hash deterministic values to runtime random values.
- Matched dropped-item vertical gravity to the player ground-movement formula by using `velocityY -= gravity * dt` with gravity `32.0`.
- Switched scene rendering to camera-relative vertex positions to reduce float precision jitter at large wrapped world coordinates.
- Added initial block `hardness` values to `assets/data/blocks.json` for future progress-based block breaking.
- Moved block breaking crack textures from `assets/textures/ui/BlockBreaking` to `assets/textures/block/breaking` and renamed them to `destroy_stage_0..9.png`.
- Implemented hold-to-break block breaking using block `hardness` and hand `breakPower = 1.0`.
- Added block breaking crack overlay stages and mining-time face particles before final block destruction.
- Doubled the RmlUi lobby title image size from `520 x 140` to `1040 x 280`.

## Decisions
- Block drop chance and count still use deterministic block/drop-entry rolls, but the visual throw direction is treated as a runtime effect and does not need deterministic replay.
- Dropped items share the player's gravity value and vertical acceleration formula, while keeping item-specific horizontal drag and simple collision.
- Gameplay and save coordinates stay in world space; only scene rendering subtracts the camera position before projection.
- Block hardness belongs to block definitions only; fluid definitions do not define hardness.
- Block breaking crack textures are treated as world block-rendering assets, not UI assets.
- `hardness` is treated as an approximate hand break time in seconds, and `breakPower` scales break speed.
