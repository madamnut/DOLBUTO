## 결정 사항
- 물 렌더 튜닝은 push constant layout을 늘리지 않고 기존 push constant slot을 재사용한다.
- 현재 물 패스가 SSR과 occlusion용 offscreen scene depth를 이미 샘플링하므로 물 흡수는 scene depth를 사용한다.
- 물 alpha는 `fresnel^4`를 사용해 grazing angle에서 완전 불투명에 가까워진다.
- 물 반사는 0이 아닌 base reflection weight를 가진 cubic Fresnel curve를 사용한다.
- 고급 물 셰이더 작업은 핵심 게임 시스템이 더 자리 잡을 때까지 미룬다.
- `amount`는 `0~100`으로 유지하고, 렌더링되는 물 표면 높이만 양자화한다.
- 단순 물 렌더링은 terrain/player depth에 의존하는 동안 scene pass 안에 유지한다.
- 기후 오버레이는 게임 렌더러가 생성하므로, 미리보기는 런타임 생성과 같은 C++ 기후 함수를 사용한다.
- Temperature noise는 precipitation과 같은 4D torus tiling 방식을 사용한다.
- 바이옴 입력은 블록별 수직 데이터가 필요 없으므로 기후는 청크 컬럼당 `uint8_t`로 저장한다.
- 플레이어 상태는 region 파일 밖에 버전 필드 없는 고정 41바이트 바이너리 레이아웃으로 저장한다.
- 런타임 로깅은 각 실행마다 latest log와 timestamped history log를 모두 쓴다.
- Prop 블록은 일반 블록 ID 레이어에 유지하며, 모델과 texture slot binding은 블록 데이터에서 정의한다.
- `dpm`은 magic과 version field 없이 quad count와 quad vertex data를 저장한다.
- Ground prop 배치는 기존 plant/tree placement salt를 재사용해 하나의 랜덤 바이트가 지면 feature를 결정한다.
- 작은 prop과 plant 렌더 오프셋은 결정적 월드 좌표 랜덤 값을 재사용하며 저장된 블록 데이터는 바꾸지 않는다.
- 블록 파괴 파티클은 런타임 전용이며, 별도 particle texture asset을 추가하지 않고 기존 블록 texture array를 재사용한다.
- 현재 terrain pipeline이 backface를 cull하므로 prop mesh는 당분간 양면으로 방출한다.
- Prop source model은 이제 `.glb`를 사용하고, 생성된 `.dpm` 파일은 런타임 캐시 데이터다.
- 로비와 메뉴 UI는 유료 UI middleware 대신 RmlUi 소스 통합을 사용한다.
- RmlUi backend sample code는 참고 자료이며, 런타임 통합은 엔진 측 UI 모듈에 둔다.
- 네이티브 메뉴 오버레이는 RmlUi 초기화 실패 시 fallback으로만 남긴다.
- 로비 배경 타일링은 타일별 sprite를 그리지 않고 기존 repeat sampler를 재사용한다.
- 앞으로 FreeType은 네이티브 디버그와 메뉴 텍스트용 font rasterizer로 사용한다.
- 렌더러는 로비에서도 살아 있지만, 게임 씬 terrain/save worker와 terrain runtime state는 게임 씬이 로드된 동안에만 활성화된다.
- 월드 시간은 application state가 소유하고 renderer에는 tick으로 전달한다. 하늘 렌더링은 renderer 안에서 해와 달 방향을 계산한다.
- 월드 생성 시각과 최근 플레이 시각은 `world.dat`에 Unix seconds로 저장하고 UI 표시용으로만 포맷한다.
- 로비 렌더링은 게임 씬과 디버그 텍스트를 완전히 건너뛰고, pause는 overlay 뒤에 게임 씬을 유지한다.
- 하늘 cycle angle은 `06H` 시작 시간 이후 해가 뜨는 방향으로 진행한다.
- 월드 선택 UI는 per-world save path routing 전에 먼저 배치하며, `CREATE`는 아직 기존 single-world runtime path로 진입한다.
- RmlUi 메뉴 문서는 이제 엔진 Vulkan renderer를 통해 렌더링한다.
- 저장된 월드 목록 활성화는 double-click을 사용해 이후 single-click selection과 scrolling을 분리할 수 있게 한다.
