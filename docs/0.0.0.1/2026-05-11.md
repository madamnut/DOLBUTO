## 작업 기록
- 인게임 디버그 오버레이에서 좌하단 chunk queue/save/load 디버그 텍스트와 우하단 peak profiler 디버그 텍스트를 제거했다.
- `R` reset과 frame, request, ensure, want, mesh request 단계의 누적 최대 millisecond 값을 표시하는 좌하단 청크 로딩 peak-latency 진단을 추가했다.
- 프레임별 peak `ensureRuntimeChunk`, saved/empty runtime miss, `wantRender` dependency request call용 resettable chunk request counter를 추가했다.
- 첫 좌하단 청크 진단 줄에 전체 프레임 `TOTAL` peak time을 추가했다.
- 저장된 청크 snapshot read를 `ensureRuntimeChunk` 밖으로 옮기고, runtime shell과 completed-load main thread 설치를 사용하는 단일 async chunk-load worker로 처리하도록 했다.
- 디버그 텍스트, 메뉴, pause UI, inventory UI에는 영향을 주지 않고 일반 게임 화면 핫바와 crosshair만 숨기거나 보이는 `F1` HUD toggle을 추가했다.

## 결정 사항
- 청크 로딩 진단을 다시 설계하는 동안 좌상단 gameplay/debug text와 우상단 hardware/render summary text는 계속 보이게 둔다.
- 청크 로딩 latency 진단은 current-frame 값 대신 마지막 `R` reset 이후의 누적 최대값을 사용한다.
- HUD visibility toggle은 플레이어가 보는 인게임 HUD 요소로 제한한다. 진단 텍스트는 계속 `F3`이 제어한다.

## 이슈
- 현재 peak-latency 병목을 특정한 뒤에는 더 넓은 청크 로딩 진단에 새 metric이 필요할 수 있다.
