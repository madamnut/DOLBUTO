## Decisions
- Player-facing HUD and inventory layout files live under `assets/ui`.
- Player UI sprite assets live under `assets/textures/ui/player`.
- Inventory is modeled as its own application screen so existing non-game input routing can handle mouse release and RmlUi input.
- Inventory is not a pause state; it keeps world ticks and player physics simulation running while suppressing movement/camera/block input.
- Item `id` is the runtime primary key, item `key` is the stable authoring/debug key, and item `name` is only a display string.
- Block drops are authored inside `blocks.json` with item keys, then resolved to item ids at load time.
- Blocks with no drops keep an explicit empty `drops` array instead of omitting the field.
- Item data uses `slotTexture` for UI icons and separate `droppedRender` / `heldRender` objects for dropped-world and held-player render data.
- Dropped items are runtime-only for now; saving and held-item rendering remain unimplemented.
- Dropped `extruded_sprite` item side meshes follow the texture alpha silhouette, but adjacent side edges are span-merged for a more stable mesh.
- Dropped `extruded_sprite` side faces sample from opaque pixel centers instead of exact alpha boundaries.
- Runtime player inventory uses one 50-slot array; slots `0` through `9` are the hotbar and the remaining slots are the main inventory.
- Dropped-item pickup inserts into existing stacks first, then empty slots, both in slot index order `0` through `49`.
- The gray slot-index debug overlay remains in code but is disabled by default.
- Third-party libraries that are not expected to be modified should live under `third_party/prebuilt` as include/lib/bin/license files; rebuild them only when version, options, runtime, or architecture changes.
- Dropped-item physics uses the item center-bottom point as its collision/contact position and advances at 20 ticks per second; rendering interpolates between physics positions.
- Dropped items can rotate around X/Y/Z while airborne, but landing preserves only Y rotation so items rest flat on the ground.
