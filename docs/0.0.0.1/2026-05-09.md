## 결정 사항
- 플레이어용 HUD와 인벤토리 레이아웃 파일은 `assets/ui` 아래에 둔다.
- 플레이어 UI sprite asset은 `assets/textures/ui/player` 아래에 둔다.
- 인벤토리는 별도 application screen으로 모델링해 기존 non-game input routing이 mouse release와 RmlUi input을 처리할 수 있게 한다.
- 인벤토리는 pause 상태가 아니다. movement/camera/block input만 억제하고 world tick과 player physics simulation은 계속 실행한다.
- 아이템 `id`는 런타임 primary key, 아이템 `key`는 안정적인 authoring/debug key, 아이템 `name`은 표시 문자열로만 사용한다.
- 블록 드랍은 `blocks.json` 안에 아이템 키로 작성하고, 로드 시점에 아이템 ID로 해석한다.
- 드랍이 없는 블록은 필드를 생략하지 않고 명시적인 빈 `drops` 배열을 유지한다.
- 아이템 데이터는 UI 아이콘용 `slotTexture`와 드랍된 월드/플레이어가 든 렌더 데이터용 별도 `droppedRender` / `heldRender` 오브젝트를 사용한다.
- 드랍 아이템은 현재 런타임 전용이다. 저장과 손에 든 아이템 렌더링은 아직 구현하지 않았다.
- 드랍된 `extruded_sprite` 아이템 옆면 메쉬는 텍스처 알파 실루엣을 따르되, 더 안정적인 메쉬를 위해 인접 옆면 edge를 span 병합한다.
- 드랍된 `extruded_sprite` 옆면은 정확한 알파 경계 대신 불투명 픽셀 중심을 샘플링한다.
- 런타임 플레이어 인벤토리는 하나의 50슬롯 배열을 사용한다. 슬롯 `0`부터 `9`는 핫바이고 나머지는 메인 인벤토리다.
- 드랍 아이템 획득은 기존 스택을 먼저 채운 뒤 빈 슬롯을 채우며, 둘 다 슬롯 인덱스 `0`부터 `49` 순서로 처리한다.
- 회색 슬롯 인덱스 디버그 오버레이는 코드에 남겨두지만 기본값으로 비활성화한다.
- 수정할 예정이 없는 서드파티 라이브러리는 `third_party/prebuilt` 아래에 include/lib/bin/license 파일로 둔다. 버전, 옵션, 런타임, 아키텍처가 바뀔 때만 다시 빌드한다.
- 드랍 아이템 물리는 아이템 중앙 하단점을 충돌/접촉 위치로 사용하고 초당 20틱으로 진행한다. 렌더링은 물리 위치 사이를 보간한다.
- 드랍 아이템은 공중에서는 X/Y/Z 축으로 회전할 수 있지만, 착지 시에는 Y 회전만 유지해 지면에 평평하게 놓인다.

## 이슈
