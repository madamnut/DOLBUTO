## 결정 사항
- 버전 변경 시 이전 버전 폴더에는 `SUMMARY.md`를 작성한다.
- 새 버전의 날짜별 작업 로그는 새 버전 폴더 아래에 작성한다.
- 빌드는 계속 사용자가 직접 수행한다.
- 유체 ID는 `0`을 없음으로 두고, `1~299`는 액체, `300~511`은 기체로 구분한다.
- 유체 셀 데이터는 상위 9비트 ID, 하위 7비트 양을 담는 `uint16_t` 패킹 값을 사용한다.
- 순환 월드는 런타임/렌더 청크 좌표를 실제 좌표로 유지하고, 저장/로드 키와 지형 생성 랜덤 입력만 래핑한다.
- LOOKAT과 블록 상호작용 레이캐스트는 로드된 청크의 블록만 대상으로 하며 유체는 포함하지 않는다.
- LOOKAT의 X/Z 좌표는 래핑된 월드 좌표만 표시한다.
- 유체는 블록과 같은 셀에 공존할 수 있으므로 런타임/저장 구조에서 블록 배열과 유체 배열을 분리한다.
- 표면 블록은 지형 최상단 위가 공기이면 `grass/dirt`, 물이면 `sand/sand`로 적용한다.

## 추가 유체 렌더링 기록

- `fluids.json`에 `id 0`, `name none` 예약값을 명시했다.
- `water`를 `assets/textures/fluid/water.png` 기반 유체 메시로 렌더링하도록 했다.
- 물 렌더링 알파를 Fresnel 기반으로 설정했다.
- 유체 높이를 `amount` 10단위 올림 기준으로 `0.1~1.0` 블록 높이에 매핑했다.
- `id 0` 유체는 JSON에 명시하되 실제 유체가 아니라 `none` 예약값으로 취급한다.
- 유체 메시와 블록 메시를 분리하고, 블록 메시를 먼저 그린 뒤 유체 메시를 그린다.
- `fluidPipeline_`을 별도로 추가하고, 일반 terrain pipeline은 non-blend로 유지했다.
- `fluidPipeline_`은 alpha blend를 켜고 depth write를 끈다.
- `fluid.frag`를 추가하고 물 알파를 Fresnel 방식으로 계산하도록 했다.
- Fresnel alpha 값은 base `0.7`, edge `0.95`, power `1.0`을 사용한다.
- 해수면은 `config/world.json`의 `terrain.seaLevel`에서 읽도록 노출했다.

## 렌더 설정 기록

- `config/render.json`을 추가했다.
- 물 Fresnel alpha가 렌더 설정의 `fluid.water.baseAlpha`, `fluid.water.edgeAlpha`, `fluid.water.fresnelPower`를 읽도록 했다.
- 물 노멀맵 설정값을 추가했다.
- `assets/textures/fluid/water_normal.jpg`를 고정 물 노멀맵으로 로드하고, `fluid.frag`에서 두 번 샘플링해 Fresnel alpha를 흔들도록 했다.
- 물용 projection-depth SSR 프로토타입을 추가했다.
- `fluid.frag`가 scene color와 scene depth를 샘플링할 수 있도록 오프스크린 scene color/depth 패스 뒤에 swapchain composite/fluid 패스를 사용하는 구조로 바꿨다.
- strength, max steps, step size, thickness, max distance, edge fade, fallback color용 `fluid.water.ssr` 설정값을 추가했다.
- 물 SSR용 `hiz.comp`와 Hi-Z mip chain을 추가했다.
- Hi-Z mip은 최소 depth를 저장하고, 정확한 mip 0 depth 확인 전에 `fluid.frag`에서 샘플링하도록 했다.
- 물 SSR Hi-Z pyramid를 projection depth에서 linear camera-space depth로 변환했다.
- `ssr.thickness`를 raw projection-depth tolerance가 아니라 linear depth tolerance로 해석하도록 했다.
- 고정 월드 거리 SSR stepping을 `fluid.frag`의 screen-space Hi-Z cell traversal로 교체했다.
- Hi-Z SSR 패스 중 Y-flipped scene sampling을 테스트했다.
- `water_normal.jpg` 파일명은 유지하면서 물 노멀 텍스처 내용을 256x256 PNG 물 노멀 소스로 교체했다.
- Hi-Z SSR compute 경로를 제거하고, 물 SSR을 가변 step 증가와 hit refinement가 있는 직접 scene depth 샘플링 방식으로 전환했다.
- Hi-Z 경로를 제거한 뒤 물 SSR scene color/depth 샘플링을 raw offscreen UV로 되돌렸다.
- 물 노멀 샘플링을 RGB 노멀맵 2회 샘플링에서 중간, 작은, 넓은 파형 디테일용 layered RG offset 샘플링으로 변경했다.
- 물 노멀 샘플링을 medium, small, broad, very broad wave scale을 가진 4개의 layered RG offset read에 맞췄다.
- 물 노멀 설정을 `normalScale`, `normalTiling`, `normalSpeed`로 단순화했다.
