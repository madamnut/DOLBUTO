## Decisions
- 버전 변경 시 이전 버전 폴더에는 `SUMMARY.md`를 작성한다.
- 새 버전의 날짜별 작업 로그는 새 버전 폴더 아래에 작성한다.
- 빌드는 계속 사용자가 직접 수행한다.
- 유체 ID는 `0`을 없음으로 두고, `1~299`는 액체, `300~511`은 기체로 구분한다.
- 유체 셀 데이터는 상위 9비트 ID, 하위 7비트 양을 담는 `uint16_t` 패킹 값을 사용한다.
- 순환 월드는 런타임/렌더 청크 좌표를 실제 좌표로 유지하고, 저장/로드 키와 지형 생성 랜덤 입력만 래핑한다.
- LOOKAT과 블록 상호작용 레이캐스트는 로드된 청크의 블록만 대상으로 하며 유체는 포함하지 않는다.
- LOOKAT의 X/Z 좌표는 래핑된 월드 좌표만 표시한다.
- 유체는 블록과 같은 셀에 공존할 수 있으므로 런타임/저장 구조에서 블록 배열과 유체 배열을 분리한다.
- 표면 블록은 지형 최상단 위가 공기이면 `grass/dirt`, 물이면 `sand/sand`로 적용한다.
