# 2026-05-14

## 작업 기록
- `Place.wav`를 블록 설치 성공 시 3D 사운드로 재생하도록 연결했다.
- `Pop.wav`를 드랍 아이템이 플레이어 인벤토리에 실제로 들어간 시점에 2D 사운드로 재생하도록 연결했다.
- `Q` 입력으로 현재 선택된 핫바 슬롯의 아이템 1개를 버리도록 했다.
- `Shift + Q` 입력으로 현재 선택된 핫바 슬롯의 스택 전체를 버리도록 했다.
- 버린 아이템은 기존 드랍 아이템 엔티티로 생성해 물리, 병합, 렌더링, 저장 흐름을 그대로 사용하도록 했다.
- 오디오 설계 문서와 아이템 데이터 설계 문서에 현재 동작을 반영했다.
- `assets/audio/music` 아래의 음악 파일을 로드해 로비 계열 화면과 인게임 화면에서 배경음악을 재생하도록 했다.
- 로비 계열 화면과 인게임 화면 전환 시 이전 음악 상태를 저장하지 않고 정지 후 새 대기 타이머를 시작하도록 했다.
- 음악은 곡 종료 후 `10초 ~ 60초` 랜덤 대기 뒤 다음 곡을 랜덤 재생하도록 했다.
- 로비 계열 화면에 진입하면 첫 음악은 대기 없이 즉시 재생하도록 했다.
- OpenAL Soft의 `AL_EXT_vorbis` 확장에 의존하던 OGG 로딩을 제거하고 `stb_vorbis` 직접 디코딩 방식으로 변경했다.
- OGG 음악은 PCM 16-bit mono/stereo로 디코딩한 뒤 OpenAL buffer로 업로드하도록 했다.
- `DOLBUTOPortable` CMake 타깃을 제거했다.
- CMake 멀티 구성 목록을 `Debug`와 `Release`로 제한했다.
- Release 출력 폴더 자체를 포터블 실행 단위로 보도록 빌드/런타임 경로 문서를 정리했다.
- 배경음악 초기 로딩 시간을 줄이기 위해 시작 시 음악 파일은 경로만 스캔하고, OGG 음악은 재생 중 OpenAL 큐 버퍼 스트리밍으로 처리하도록 변경했다.
- OGG 음악 스트리밍은 2초 분량 버퍼 3개를 돌려 쓰며, WAV 음악은 재생 직전에 단일 버퍼로 로드하는 예외 경로로 남겼다.
- 좌하단 청크 피크 디버그 텍스트를 화면에 표시하지 않도록 제거했다.
- 좌하단 청크 피크 디버그의 `R` 초기화 입력과 내부 누적 계측 로직도 제거했다.
- 저장된 청크 snapshot이 비동기 로드로 런타임에 설치된 뒤 주변 3x3 메쉬 조건을 다시 검사하도록 해, 월드 재진입 직후 청크 경계를 넘기 전까지 지형이 렌더링되지 않던 문제를 수정했다.

## 결정 사항
- 아이템 버리기는 인게임 상태에서만 처리한다.
- 드랍 엔티티 생성에 실패하면 인벤토리 슬롯은 차감하지 않는다.
- 블록 설치음은 설치된 블록 중심 위치를 사용한다.
- 아이템 획득음은 획득 시점 피드백이므로 2D 사운드로 처리한다.
- 음악 파일 디렉터리는 씬별로 나누지 않고 `assets/audio/music` 하나를 사용한다.
- 음악 씬 전환은 재개가 아니라 리셋으로 처리한다.
- OGG 음악 재생은 시작 시 전체 디코딩하지 않고 스트리밍한다.
- OGG 음악 재생은 OpenAL 런타임 확장이 아니라 프로젝트에 포함한 `stb_vorbis` 디코더를 사용한다.
- 포터블 배포는 별도 타깃을 사용하지 않고 Release 출력 폴더를 폴더째 배포하는 방식으로 정리한다.
- 빌드 구성은 `Debug`와 `Release`만 사용한다.
- 좌하단 청크 피크 디버그는 화면 출력과 내부 계측을 모두 사용하지 않는다.
- 빌드는 사용자가 직접 수행한다.
- 저장 청크를 복원하는 경로도 새로 생성된 청크 완료 경로처럼 주변 메쉬 큐잉 조건을 다시 확인한다.

## 이슈
- 빌드는 실행하지 않았다.
