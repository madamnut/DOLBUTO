# 일반 지형 nonempty 목록 · 전후 비교 · 2026-10-01

AI 작업 컨텍스트. 사용자 `비교까지해봐그럼`으로 앞선 조사에서 추천한 nonempty 청크 목록을 적용하고 헤드리스 전후 비교를 승인했다. 비교 기준은 세부 계측 기능까지 들어간 직전 빌드이며, 이전 LOD 최적화는 두 버전 모두 포함한다.

## 변경

Resident 컬럼에32비트 `nonempty_meshes`를 추가한다. 각 비트는 해당 세로 청크의 mesh.count>0 여부다. 컬럼 업로드 완료 후 등록 시32개를 한 번 확인해 초기화하고, resident geometry가 교체되면 해당 비트를 set/clear한다. lighting-only 교체는 count가 같으므로 유지한다. 컬럼 퇴거/재생성 때 함께 폐기되어 별도 포인터 캐시 수명 문제가 없다.

주 화면 일반 지형 루프는 마스크의 최하위 비트부터 읽어 실제 내용 있는 청크만 방문한다. 기존 cy 오름차순, 상대 좌표 계산, 매 프레임 시야 검사, 선택 블록, Vulkan push/bind/draw, 물·얼음 목록 구성을 유지한다. 그림자 루프, LOD, 컬럼 전체를 제외하는 새 컬링은 변경하지 않았다. 최대32청크를 static_assert로 확인한다.

`--profile-near-detail`에서는 전체 mesh.count로 기대 마스크를 다시 만들어 캐시 일치 여부를 확인한다. 불일치는 명시적 오류이며 이 검증 비용은 성능 실행에 포함하지 않는다. CSV의 near_chunk_slots는 실제 방문량으로서 이전32×컬럼에서 nonempty 개수로 줄어든다.

## 검증 범위

Release 빌드 성공(`build/near-mask-build.log`), clang-format/git diff --check 통과. 별도 before/after validation ON/세부 계측 ON/거리12/64steady 실행은 모두exit0/Vulkan errors0, 기존 미사용 셰이더 출력 warnings10, UI issues0, texture failures0이었다. 캐시 일치 검사는 초기 로딩부터 종료까지 성공했다. 거리12의 방문 슬롯은14112→882, nonempty882와 visible/draw209는 같았다. 그림자 원본4종 및 extent.txt SHA256도 전후 일치했다.

성능18회 모두exit0/Vulkan/UI/texture 오류0. CPU/GPU steady frame 일치, 각640표본, LOD pending/queued0 및 바인딩 카운터 관계를 확인했다. 거리32 전후 PNG를 직접 읽어 지형·하늘·그림자·선택 표시·HUD를 확인했다. 전체9쌍의 평균 절대 RGB 채널 차이 최대0.337954/255, 개별 채널 최대45이며 픽셀 완전 동일은 아니다. 종료 프레임/TAA 이력 등이 다르므로 그 차이의 원인을 전부 하나로 단정하지 않는다.

코드상 최초 등록·resident geometry 교체·lighting-only 교체·컬럼 퇴거·재생성 경로의 마스크 수명을 확인했다. 이번 런타임 검증은 초기 스트리밍과 고정 평지이며 이동/실제 블록·유체 편집/재생성 조작/다른 GPU는 포함하지 않는다. 자동 테스트/CTest/CU/합성 입력을 추가하거나 사용하지 않았다.

효과가 관측되어 변경을 유지하고 `out/DOLBUTO`에 패키징했다(`build/near-mask-package.log`). build/bin·after.exe·out 실행 파일의 위 SHA256 일치, 격리 settings.json SHA256 보존. 배포 폴더에 사용자 JSON을 새로 쓰지 않았다. 이번 변경은 commit/push하지 않았다.
