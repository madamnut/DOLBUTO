# 2026-05-18

## Spline editor
- Changed Save JSON behavior so curves loaded from an existing JSON path are overwritten directly. New/reset curves still ask for a path on first save.
- The editor status now shows the current JSON file name or `new curve`.
- Removed the native Windows drag/drop hook after it could still terminate the editor on drop.
- Added optional `tkinterdnd2` support for JSON drag/drop. If the package is unavailable, the editor still runs normally and JSON loading remains available through `Load JSON`.
- Added startup path loading so dragging a JSON file onto the `.pyw` launcher opens that file through `sys.argv`.

## Terrain PV LUT cleanup
- Removed `pv_baseline_lut.json`, `pv_baseline_lut.bin`, `pv_influence_lut.json`, and `pv_influence_lut.bin`.
- Removed the matching diagnostics/config load and terrain-builder config fields. PV sampling remains available through weirdness/PV debug values.
- Added initial `pv_weight_lut.*`, `groundness_pv_weight_lut.*`, and `smoothness_pv_weight_lut.*` curves for future `pvWeight = PV * GND * SMTH` terrain-value factor work.
- Wired the PV weight LUTs into terrain generation. The raw GND/SMTH/BASE value is normalized from `-3.5..3.5` to `0..2`, then multiplied by `1 - pvWeight`.
- Updated `height_lut.*` to use `0..2` input and expanded the terrain debug text to show `RAW`, `NORM`, `PVW`, `PVMUL`, `VAL`, and `H`.
