# 2026-05-18

## 작업 기록
- `SplineEditor`에서 기존 JSON 경로로 연 곡선은 `Save JSON` 시 같은 파일에 바로 덮어쓰도록 변경했다. 새 곡선이나 reset 곡선은 첫 저장 때 경로를 묻는다.
- 상태 표시줄에 현재 JSON 파일명 또는 `new curve`를 표시하도록 했다.
- 드롭 시 에디터가 종료될 수 있던 Windows native drag/drop hook을 제거했다.
- `tkinterdnd2`가 있으면 JSON drag/drop을 지원하고, 없으면 기존 `Load JSON`만 사용하도록 했다.
- `.pyw` 실행 인자로 JSON 경로가 들어오면 시작 시 해당 파일을 열도록 했다.
- `pv_baseline_lut.json`, `pv_baseline_lut.bin`, `pv_influence_lut.json`, `pv_influence_lut.bin`을 제거했다.
- 관련 diagnostics/config load와 terrain-builder config field를 정리했다. PV 샘플링 자체는 weirdness/PV debug 값으로 유지했다.
- `pv_weight_lut.*`, `groundness_pv_weight_lut.*`, `smoothness_pv_weight_lut.*` 초기 곡선을 추가했다.
- terrain generation에 PV weight LUT 경로를 연결했다. GND/SMTH/BASE로 만든 raw value를 `-3.5..3.5`에서 `0..2`로 정규화한 뒤 `1 - pvWeight`를 곱하도록 했다.
- `height_lut.*` 입력 범위를 `0..2`로 바꾸고, terrain debug text에 `RAW`, `NORM`, `PVW`, `PVMUL`, `VAL`, `H`를 표시하도록 확장했다.

## 결정 사항
- PV는 baseline/influence 축이 아니라 최종 terrain value를 누르는 weight 축으로 사용한다.
- `SplineEditor`의 export는 height 전용 round/clamp를 하지 않고 spline 그래프 값을 float 샘플로 그대로 저장한다.

## 이슈
- drag/drop은 환경 의존성이 있으므로, `tkinterdnd2`가 없는 환경에서는 파일 선택 방식만 보장한다.
