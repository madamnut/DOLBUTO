## 결정 사항
- 우클릭 삭제는 실수 위험이 있어 별도 편집 창의 Delete 버튼으로 옮겼다.
- 드래그 중 정렬로 대상 점이 바뀌지 않도록 드래그 대상은 인덱스가 아니라 점 객체 참조로 유지한다.
- spline 편집기는 height LUT 외에도 Groundness Baseline/Influence 같은 곡선을 편집할 수 있도록 X/Y 범위를 에디터 상태로 둔다.
- SplineEditor는 범용 도구이므로 export도 height 전용 clamp/round를 하지 않고 spline 그래프 값을 float로 그대로 저장한다.
- Groundness는 큰 바다/해안/땅 성향을 정하고, Baseline은 terrainValue 기준값, Influence는 local baseNoise 영향력으로 사용한다.
- Smoothness는 높이대를 직접 덮어쓰는 값이 아니라 baseNoise의 거칠기와 진폭을 조절하는 지형 파라미터로 사용한다.
- Weirdness는 1 octave raw noise로 유지하고, `PV = 1 - abs(3 * abs(weirdness) - 2)` 값은 우선 진단용으로만 사용한다.
