# 2026-05-22

## 작업 기록
- 플레이어 HP 테스트용 `PlayerStats`를 추가하고, HUD 좌하단에 `Gauge.png`/`Bar.png` 기반 세로 HP 게이지를 배치했다.
- 채팅 명령어 `/stat`, `/stat <hp|hunger|thirst> add <value>`, `/stat <hp|hunger|thirst> set <value>`를 추가해 스탯 게이지를 런타임에서 테스트할 수 있게 했다.
- HUD 좌하단 스탯 게이지를 HP/허기/갈증 3종으로 확장하고, 각각 붉은색/황갈색/파란색 바를 사용하도록 정리했다.
- 채팅 패널을 스탯 게이지와 같은 좌측 padding에 맞추고, 게이지를 가리지 않도록 위쪽으로 올렸다.
- 스탯 바 fill 갱신을 RmlUi `style` attribute 문자열 교체 방식에서 `SetProperty(PropertyId::Height, ...)` 방식으로 변경해 런타임 값 변경이 레이아웃에 직접 반영되도록 했다.
- 스탯 바가 RmlUi overflow clip에 의존하지 않도록 `Bar.png` 클리핑 구조를 제거하고, 색상 사각형 바 요소 자체의 높이를 직접 바꾸는 구조로 변경했다.
- `Survival`/`Sandbox` 게임모드를 추가하고 `/gamemode survival`, `/gamemode sandbox` 명령어를 추가했다.
- 월드 생성 화면에 클릭할 때마다 `SURVIVAL`/`SANDBOX`가 전환되는 게임모드 토글 버튼을 추가하고, `player.dat`에 게임모드와 HP/허기/갈증 스탯을 저장하도록 플레이어 저장 포맷을 확장했다.
- Survival에서는 `Space` 더블탭 fly 전환을 막고, Sandbox에서는 기존 ground/fly 전환 흐름을 유지하도록 했다.
- 밤하늘에서 보이던 줄무늬를 줄이기 위해 `sky.frag`의 선형 screen-space dither를 hash noise 기반 dither로 교체했다.
- 밤하늘 ramp 색을 더 낮춰 밤 시간대 하늘이 더 어둡게 보이도록 조정했다.
- 정지 상태에서 Ctrl 또는 sprint toggle만으로 월드 FOV가 달리기 값으로 올라가지 않도록, 달리기 FOV 목표값을 실제 수평 이동량 기준으로 조정했다.
- 좌하단 `PERF MAX` 디버그 텍스트 표시를 제거했다. 피크 값 문자열은 더 이상 매 프레임 렌더 프레임에 전달하지 않는다.

## 결정 사항
- 하늘 계조 보정은 별도 texture를 추가하지 않고 fullscreen sky shader 내부의 작은 hash dither로 처리한다.
