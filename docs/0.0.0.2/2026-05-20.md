# 2026-05-20

## 작업 메모
- 1인칭 손 viewmodel 설정을 reach/pull 보정값 대신 직접 조정 가능한 `x/y/z`, `scale`, `rotationX/rotationY/rotationZ` 구조로 변경했다.
- 1인칭 손 mesh 추출 범위를 오른팔 전체에서 `Arm_RL` 아래팔 계열 node로 좁혔다.
- 1인칭 viewmodel 렌더링 직전에 scene depth를 clear하고, viewmodel pipeline은 depth test/write를 켜서 손/아이템 mesh 내부 depth가 정상 반영되도록 했다.
- 1인칭 손 mesh 배치 단계에서 local X축을 고정 반전해 화면상 좌우 뒤집힘을 보정했다.
- 실제 수평 이동량 기반 `playerWalkPhase`/`playerWalkAmount`를 추가하고, 플레이어 GLB node transform 단계에서 팔/다리 2구간 보행 모션을 적용했다.
- 몸 방향은 카메라 yaw를 따라가고, 뒤/좌/우 이동 시에도 몸 전방을 유지하도록 조정했다. 보행 phase/amount/body yaw는 렌더 alpha로 보간해 물리 tick 사이 모션 끊김을 줄였다.
- 좌우 이동 입력이 있을 때 body yaw 목표에 전방 기준 좌우 `45도` 오프셋을 적용해 옆걸음 방향으로 몸이 살짝 틀어지도록 했다.
- 팔꿈치와 무릎 bend는 한 방향으로만 꺾이고 지정된 각도 상한을 넘지 않도록 제한했다.

## 작업 기록
- 1인칭 화면에서 표시할 손/아이템 렌더링 경로를 추가했다.
- `ClientFrame`과 `RendererFrame`에 1인칭 손 표시 여부와 선택 핫바 아이템 id를 전달하는 필드를 추가했다.
- `PlayerMeshRenderPath`가 `Character.glb`의 오른팔 아래팔 node를 별도 hand mesh로 추출하고, 카메라 기준 오른쪽 아래에 매 프레임 배치하도록 했다.
- 선택 핫바 슬롯에 아이템이 있으면 기존 드랍 아이템용 extruded sprite 렌더 경로를 재사용해 손 앞에 표시하도록 했다.
- 1인칭 손/아이템을 viewmodel 전용 pipeline으로 분리하고 그리기 직전 scene depth를 clear해 지형에 묻히지 않도록 했다.
- 아이템을 들고 있을 때는 손을 숨기고 아이템만 표시하도록 했다.
- 든 아이템 전용 `item_viewmodel.vert`를 추가해 카메라 회전과 무관하게 같은 면이 보이도록 했다.
- `config/viewmodel.json`을 추가하고 손/아이템 viewmodel 위치, 스케일, 회전, 포즈 보정값을 설정 파일에서 읽도록 했다.
- 든 아이템 viewmodel scale 값을 `config/viewmodel.json`에서 조정할 수 있도록 했다.
- `docs/design/player.md`와 `docs/design/rendering.md`에 현재 1인칭 손/아이템 렌더링 구조를 반영했다.

## 결정 사항
- 1인칭 손은 새 모델 파일을 만들지 않고 현재 플레이어 GLB의 오른팔 파트를 재사용한다.
- 손에 든 아이템은 당분간 드랍 아이템과 같은 `DroppedItemRenderPath`를 재사용한다.
- 1인칭 viewmodel은 월드 scene depth를 사용하지 않지만, viewmodel 내부 depth test/write는 사용한다.

## 이슈
- 실제 화면 배치와 회전값은 사용자 빌드 실행 후 시각적으로 조정할 수 있다.
