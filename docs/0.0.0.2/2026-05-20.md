## 이동 조작 갱신
- `V` 키 fly/ground 토글을 제거하고, `Space` 더블탭으로 ground/fly 모드를 전환하도록 변경했다.
- fly 모드에서는 `Ctrl`을 누르는 동안 `1.3`배 가속하고, `Shift` 하강 중 지면에 닿으면 ground 모드로 복귀하도록 했다.
- ground 모드에서는 `Ctrl` 또는 `W` 더블탭으로 달리기를 시작하고, `Shift`로 웅크리도록 했다.
- 달리기 속도 배율은 `1.3`, 웅크리기 속도 배율은 `0.3`, 웅크리기 높이 배율은 `0.833333`, 더블탭 시간은 `0.35`초로 `config/world.json`에 추가했다.
- Options 화면에 SPRINT/SNEAK hold-toggle 설정 버튼을 추가하고, `config/settings.json`의 `controls`에 저장하도록 했다.
- 웅크리기 높이 배율이 플레이어 지형 충돌과 블록 설치 충돌 판정에 반영되도록 gameplay collision 경로에 height scale을 전달했다.

## FOV 옵션
- Options 화면에 `FOV` 슬라이더를 추가하고 `30도 ~ 110도` 범위에서 조정하도록 했다.
- `config/settings.json`의 `video.fovDegrees`에 FOV 값을 저장하고, 기본값은 기존 렌더링과 같은 `60도`로 유지했다.
- `ClientFrame`과 `RendererFrame`에 `fovRadians`를 추가해 렌더 투영행렬, terrain/dropped item 프러스텀 컬링, 해/달 화면 투영이 같은 FOV 값을 쓰도록 했다.

## Fly 전환 입력
- `Space` 더블탭 규칙을 ground/fly 양방향 전환으로 바꿨다.
- ground 모드에서 `Space` 더블탭하면 fly로 진입하고, fly 모드에서 `Space` 더블탭하면 ground로 돌아간다.
- 단일 `Space` 입력은 기존처럼 ground 점프 또는 fly 상승으로 유지했다.

## Viewmodel FOV 분리
- 1인칭 손과 든 아이템 viewmodel은 FOV 옵션의 영향을 받지 않도록 기존 `60도` 고정 투영을 유지했다.
- 월드, 플레이어, 파티클, 선택선, 드랍 아이템, 프러스텀 컬링, 하늘 투영만 Options FOV 값을 사용한다.

## Sprint FOV
- 달리기 중 월드 FOV 목표값을 현재 Options FOV의 `1.15`배로 보정하도록 했다.
- sprint FOV 보정값은 물리 tick에서 부드럽게 보간하고, 렌더 alpha로 다시 보간해 프레임에 전달한다.
- 동적 sprint FOV 결과에는 별도 최대값 clamp를 걸지 않고, Options FOV 입력값만 `30도 ~ 110도`로 제한한다.
- 1인칭 손과 든 아이템 viewmodel은 계속 `60도` 고정 투영을 사용한다.

## Sneak edge guard
- ground 웅크리기 중 수평 이동 시 플레이어 바닥 사각형 아래에 충돌 지형이 하나도 남지 않는 위치로는 이동하지 않도록 했다.
- 지지 판정은 `BlockInteractionSystem`에 두고, `ClientGameplayRuntime`과 `ClientRuntime`을 통해 `GameClient` 이동 처리에서 사용한다.
- 기존 축별 충돌 보정 binary search에도 같은 지지 조건을 적용해 블록 끝에서 경계까지는 이동하되 떨어지는 방향으로는 더 진행하지 않도록 했다.

## PlayerMovementSystem 분리
- `GameClient::updatePlayer()`에 있던 fly/ground 이동, 점프/낙하, 달리기/웅크리기 속도, 충돌 stepping, 보행 모션 값, sprint FOV 보간을 `PlayerMovementSystem`으로 옮겼다.
- `GameClient`는 GLFW 입력 상태, movement 설정값, collision callback을 전달하고 결과 player state만 반영하도록 축소했다.
- `PlayerMoveMode`, `PlayerMovementInput`, `PlayerMovementState`, `PlayerMovementConfig`, `PlayerMovementCollision`을 명시적인 DTO로 두어 이동 규칙과 클라이언트 배선을 분리했다.

## Sneak camera smoothing
- 웅크리기 충돌 높이는 즉시 적용하되, 카메라 눈높이는 `PlayerMovementState::eyeHeightScale`로 따로 보간하도록 했다.
- 렌더 프레임에서는 이전 tick 눈높이 배율과 현재 tick 눈높이 배율을 physics alpha로 다시 보간해 앉기/일어서기 때 카메라가 순간 이동하지 않게 했다.

## View Bobbing
- 렌더 전용 `CameraViewBob`을 추가해 ground 이동 중 카메라 위치에만 좌우/상하 보빙을 적용하도록 했다.
- 보빙은 `walkPhase`와 실제 수평 이동량 기반 `walkAmount`를 사용하며, `walkAmount` 상한을 `1.35`로 늘려 웅크리기/걷기/달리기 속도 차이가 강도에 반영되게 했다.
- 카메라 방향과 블록 상호작용 raycast는 보빙 영향을 받지 않도록 유지했다.
- Options 화면에 `BOBBING VIEW` ON/OFF 토글을 추가하고 `config/settings.json`의 `video.viewBobbing`에 저장하도록 했다.
