## 결정 사항
- `0.0.0.1`의 `SUMMARY.md`는 이전 버전 요약으로 유지한다.
- `0.0.0.2`의 개발 기록은 `docs/0.0.0.2/` 아래에 누적한다.
- 빌드는 사용자가 직접 수행한다.
- 현재 README는 별도 포터블 생성 타깃이 아니라 Release 출력 폴더 자체를 포터블 실행 단위로 설명한다.
- 초기 타입 분리 시점에는 worker queue와 저장/로드 실행 로직을 `Renderer`에 남겼지만, 이후 저장/로드 실행은 `SaveSystem`으로 분리했다.
- 데이터 정의 파싱은 렌더링 리소스 생성과 분리하되, 텍스처 레이어 배정과 GPU 리소스 생성은 아직 `Renderer`에 남긴다.
- 설정 파일의 경로 해석은 기존 런타임 경로 기준을 따르고, 설정 값의 해석과 클램프는 `ConfigLoaders`로 분리한다.
- 소품 모델 파일 형식 변환과 DPM 파일 검증은 렌더러가 아니라 asset loader 책임으로 둔다.
- OpenAL device/context와 오디오 재생 상태는 `AudioSystem`이 소유하고, 재생 시점 판단은 기존처럼 `Renderer`의 게임/UI 흐름에서 결정한다.
- RmlUi 수명주기와 문서/이벤트 소유권은 `UiSystem`으로 옮기되, Vulkan UI 렌더링은 아직 `Renderer`에 남긴다.
- RmlUi 문서 element 조작은 `UiSystem`으로 모으고, 인벤토리 상태 판단과 아이템 표시 데이터 해석은 아직 `Renderer`에 남긴다.
- 인벤토리 UI 표현 계산은 `InventoryUi`로 옮기고, `InventoryUi`는 런타임 인벤토리 상태를 소유하지 않는 순수 표시 helper로 둔다.
- GLFW 입력을 RmlUi 입력으로 변환하는 책임은 `RmlInput`에 두고, `UiSystem`은 변환 결과를 RmlUi context로 전달한다.

## 이슈
- 빌드는 실행하지 않았다.

- 저장 payload 직렬화/역직렬화와 LZ4 block encode/decode를 `src/save/SaveFormat.h/.cpp`로 분리했다.
- save worker, 저장 큐, pending snapshot, clean revision cache, region header cache, region file IO, 저장/로드 카운터를 `src/save/SaveSystem.h/.cpp`로 분리했다.
- `Renderer`는 runtime chunk에서 `SaveChunkSnapshot`을 만들고 snapshot을 runtime chunk로 복원하는 경계만 유지하며, 저장/로드 실행은 `SaveSystem`에 위임하도록 연결했다.
- 저장 시스템 분리 내용을 `CMakeLists.txt`, `docs/design/project-overview.md`, `docs/design/chunk-system.md`, `docs/design/save-load.md`에 반영했다.
- Removed the obsolete renderer save worker, region IO, payload serialization helpers, and cache members after the `SaveSystem` handoff.
- Added `src/world/ChunkLoadSystem.h/.cpp` for chunk-load worker ownership, snapshot load request queue, completion queue, and duplicate request tracking.
- `Renderer` now starts/stops/enqueues/drains chunk snapshot loads through `ChunkLoadSystem` and keeps only runtime snapshot installation logic.
- Updated `CMakeLists.txt`, `docs/design/project-overview.md`, `docs/design/chunk-system.md`, and `docs/design/save-load.md` for the chunk-load worker split.
- Added `src/world/TerrainJobSystem.h/.cpp` for terrain worker thread ownership, terrain job queues, completion queues, and job priority selection.
- `Renderer` now starts/stops/enqueues/drains terrain work through `TerrainJobSystem` while keeping terrain generation, feature application, mesh build callbacks, and completion installation.
- Updated `CMakeLists.txt`, `docs/design/project-overview.md`, and `docs/design/chunk-system.md` for the terrain job system split.
- Added `src/world/TerrainBuilder.h/.cpp` for heightmap generation, initial chunk block/fluid fill, climate column fill, tree feature write generation, and feature write application.
- Terrain worker `BuildFeaturing` and `FinalizeFeatures` paths now call `TerrainBuilder`; `Renderer` keeps runtime installation, mesh build, and Vulkan upload ownership.
- Updated `CMakeLists.txt`, `docs/design/world-generation.md`, `docs/design/chunk-system.md`, and `docs/design/rendering.md` for the terrain builder split.
- Replaced the remaining renderer terrain-generation, tree-feature, feature-apply, chunk heightmap, and chunk climate helper bodies with `TerrainBuilder` delegation wrappers.
- Removed obsolete renderer-only terrain height LUT conversion helpers and the unused renderer terrain seed wrapper after the `TerrainBuilder` handoff.
- Added `src/world/TerrainMesher.h/.cpp` for chunk mesh orchestration and edited subchunk neighbor sampling.
- `Renderer::buildChunkMesh` and `Renderer::buildEditedSubchunkMesh` now delegate orchestration to `TerrainMesher` while keeping the solid subchunk mesh builder as a callback.
- Moved fluid subchunk mesh generation into `TerrainMesher`; `Renderer` now supplies the opaque-block predicate used by fluid face culling.
- Removed the obsolete renderer `buildMeshingBlocks` path and related unused terrain block-generation helpers.
- Updated `CMakeLists.txt`, `docs/design/project-overview.md`, `docs/design/chunk-system.md`, and `docs/design/rendering.md` for the terrain mesher split.
