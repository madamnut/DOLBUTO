# 2026-05-23

## 렌더링 조명

- 플레이어 스킨, 1인칭 손, 손에 든 아이템, 드랍 아이템, 블록 파괴 파티클이 지형과 같은 packed light와 시간대별 `skyBrightness`를 사용하도록 연결했다.
- 플레이어/뷰모델 계열은 플레이어 위치의 light를 샘플링하고, 드랍 아이템/파티클은 각 렌더 위치의 light를 샘플링한다.
- item instance buffer에 sky/block light를 추가하고, item/player/particle shader가 hardcoded fullbright 대신 vertex/instance light를 fragment lighting으로 넘기도록 정리했다.

## 월드 생성

- 새 월드 생성 시 초기 플레이어 스폰을 `Z = 16384`, seed 기반 랜덤 X 후보에서 찾도록 했다.
- 후보 column의 표면 블록이 `grass`이면 `surfaceY + 1`을 `player.dat` 초기 위치로 저장하고, 그 좌표 기준으로 게임 씬 로딩을 시작한다.
- Sandbox 모드로 새 월드를 생성해도 초기 `player.dat`의 이동 모드는 ground로 저장하도록 변경했다.
