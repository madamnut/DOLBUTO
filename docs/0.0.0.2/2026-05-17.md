# 2026-05-17

## Terrain formula test
- Added `assets/data/test/groundness_test.html` modes for `GND`, `SMTH`, `W`, `PV`, `baseNoise`, `landBase`, `reliefAmount`, `ridgeMask`, `valleyMask`, `detailRelief`, `ridgeContribution`, `valleyContribution`, and `VAL`.
- The test formula is `VAL = landBase + detailRelief + ridgeContribution - valleyContribution`, separate from the current in-game terrain formula.

## Terrain height formula
- Removed PV baseline/influence from the in-game height formula while keeping weirdness/PV sampling for diagnostics and future river-mask work.
- The current terrain value is `GroundnessBaselineLUT(GND) + baseNoise * GroundnessInfluenceLUT(GND) * SmoothnessInfluenceLUT(SMTH)`.
- Removed `smoothness_baseline_lut.json` and `smoothness_baseline_lut.bin`; Smoothness now only contributes through `smoothness_influence_lut`.

## 작업 기록
- F6 진단 오버레이 순환을 `OFF -> Temperature -> Precipitation -> Groundness -> Smoothness -> Weirdness -> PV -> OFF`로 확장했다.
- temperature/precipitation 오버레이는 기존처럼 `65536 x 65536` 전체 타일 월드를 `1024 x 1024` 텍스처로 축소 샘플링한다.
- groundness/smoothness/weirdness/PV 오버레이는 월드 원점 기준 `0..4096` 블록 영역을 `1024 x 1024` 텍스처로 축소 샘플링한다.
- `TerrainBuilder`에 mode별 terrain debug noise 생성 경로를 추가해 F6 지형 오버레이가 필요한 노이즈만 계산하도록 했다.
- groundness/smoothness 오버레이는 `-1..1` 값을 색상 밴드 기준으로 쓰고, 범위 밖 값은 양 끝 색으로 고정한다.
- weirdness/PV 오버레이는 `-1..1` 값을 반전 흑백으로 표시해 높은 값일수록 검정, 낮은 값일수록 흰색이 된다.
- `pv_baseline_lut.*`, `pv_influence_lut.*` 초기 곡선을 추가했다.
- 월드 높이 계산에서 `baseline = GND_BASE + SMTH_BASE + PV_BASE`, `influence = GND_INF * SMTH_INF * PV_INF`가 되도록 연결했다.

## 결정 사항
- 지형 노이즈 오버레이는 전체 월드 지도가 아니라 `4096 x 4096` 블록 영역 확대 진단용으로 본다.
- `weirdness`는 직접 높이에 반영하지 않고 PV를 만드는 원본 입력으로만 사용한다.
- PV는 baseline과 influence spline을 모두 가지며, 낮은 PV는 골짜기/강 후보, 높은 PV는 능선/산맥 후보를 만드는 약한 보정축으로 사용한다.
