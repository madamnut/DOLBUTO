# 2026-05-19

## Biome debug
- Added a first-pass biome classifier for diagnostics using only `temperature`, `precipitation`, and `groundness`.
- Temperature and precipitation use 3 bands each. Groundness uses `0` for ocean when `GND < 0` and `1` for land otherwise.
- Added land and ocean 3x3 biome tables and display the result under the climate line as `BIOME: T[n] P[n] GND[n] - BiomeName`.

## HUD chat input
- Added an RmlUi chat panel to the HUD at the lower-left of the game screen.
- Enter opens the chat input in game. Enter with empty text closes it, and Enter with text submits it to the local chat log.
- Escape closes the chat input without submitting. `/` no longer has any special open behavior.
- After submission, chat history remains on the HUD as text-only transparent overlay while the input box is hidden.
- While chat is open, game movement, hotbar scroll, block break/place, and gameplay hotkeys are consumed by the UI path instead of gameplay.
- The chat input uses RmlUi text input, key modifiers, and GLFW clipboard integration so selection and copy/paste shortcuts such as Ctrl+A/C/V stay on the text control.

## Local chat commands
- Added `src/game/CommandSystem.h/.cpp` as a local slash-command parser for HUD chat submissions.
- Added `/help`, `/pos`, `/seed`, `/tp <x> <y> <z>`, `/time set <ticks>`, and `/time add <ticks>`.
- `/tp` supports absolute coordinates plus Minecraft-style relative coordinates: `~`, `~10`, and `~-5`.
- Command output is appended as `System:` chat messages, while normal submitted chat remains `You:`.

## Player GLB model path
- Replaced the old `Character.mesh` runtime player mesh with direct loading from `assets/textures/character/Character.glb`.
- Added `PlayerModelLoader` to parse GLB node, mesh primitive, vertex, UV, and index data while preserving the source node index per vertex.
- Updated `PlayerMeshRenderPath` to keep GLB node transforms and apply them every frame before scaling the model by `1 / 16` and placing it at the player position.
- The new player model keeps named parts such as `Head`, `BodyRoot`, `Arm_L`, `Arm_R`, `Leg_L`, and `Leg_R` for future head rotation and walking motion.

## Player head rotation
- Split camera yaw from rendered body yaw for the player model.
- Added head yaw and head pitch values to `ClientFrame` and `RendererFrame`.
- The head follows the camera immediately, clamps relative yaw to `-45` through `+45` degrees, and clamps pitch to `-70` through `+70` degrees.
- When camera yaw exceeds the head yaw limit, body yaw is corrected immediately so the head remains inside the limit.
- `PlayerMeshRenderPath` applies the head yaw/pitch transform only to the `Head` GLB node.

## Options screen
- Added `assets/ui/options.rml` and wired an `OPTIONS` button into both the lobby and pause menus.
- Options uses the shared RmlUi menu routing with `menuOverlayMode == 6`, returning to the screen that opened it.
- Added BGM and SFX volume controls using RmlUi range sliders and percent labels.
- Options uses the lobby-style background when opened from the lobby, and a translucent pause overlay when opened from pause.
- Added `settings.json` loading/saving under the config directory with `audio.bgmVolume` and `audio.sfxVolume`.
- Added runtime audio volume application so music source gain uses BGM volume and all SFX playback gain is multiplied by SFX volume.

## Block alpha blend path
- Added `alphaBlend` to block data parsing and runtime block definitions.
- Split terrain CPU mesh output into solid and blend subchunk data so `alphaMode = "blend"` blocks can render outside the opaque terrain path.
- Added a terrain blend pipeline that uses the terrain texture array with alpha blending enabled and depth write disabled.
- Packed per-block `alphaBlend` into terrain material data and applied it in `terrain.frag`.
- Registered `gravel` as an opaque cube block and `ice` as a blend cube block using `alphaBlend = 0.55`.

## Biome surface rules
- Added a shared `world::Biome` classifier using 5 temperature bands, 5 precipitation bands, and ocean/land groundness bands.
- Updated biome debug text to use the shared 5-band classifier.
- Applied biome-based air/underwater surface and subsurface block rules during terrain generation.
- FrozenOcean keeps sand seabed blocks, but replaces the top sea-level water cell with an `ice` block while leaving deeper cells as water.
