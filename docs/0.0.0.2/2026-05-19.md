## 작업 기록
- temperature, precipitation, groundness만 사용하는 1차 biome classifier를 진단용으로 추가했다.
- 초기 classifier는 temperature/precipitation을 각각 3단계로 나누고, groundness는 `GND < 0`이면 ocean `0`, 아니면 land `1`로 나누도록 했다.
- land/ocean 3x3 biome table을 추가하고 climate line 아래에 `BIOME: T[n] P[n] GND[n] - BiomeName` 형식으로 표시했다.
- HUD 좌하단에 RmlUi 기반 chat panel을 추가했다.
- 게임 중 `Enter`로 chat input을 열고, 빈 입력 상태에서 `Enter`를 누르면 닫히며, 텍스트가 있으면 local chat log에 제출하도록 했다.
- `Escape`는 제출 없이 chat input을 닫고, `/` 키는 chat을 여는 특수 동작을 하지 않도록 했다.
- chat 제출 후에는 입력칸을 숨기고, 채팅 내역은 투명한 text-only overlay로 HUD에 남도록 했다.
- chat이 열려 있을 때는 이동, hotbar scroll, block break/place, gameplay hotkey가 UI 경로에서 소비되도록 했다.
- RmlUi text input, modifier key, GLFW clipboard 연동을 사용해 `Ctrl+A/C/V` 같은 선택/복사/붙여넣기 단축키가 입력 컨트롤에서 동작하도록 했다.
- `CommandSystem`을 추가해 HUD chat 제출을 local slash-command로 파싱하도록 했다.
- `/help`, `/pos`, `/seed`, `/tp <x> <y> <z>`, `/time set <ticks>`, `/time add <ticks>` 명령어를 추가했다.
- `/tp` 좌표는 `~`와 `~offset` 상대 좌표를 지원하도록 했다.
- 명령어 결과는 `System:` chat message로, 일반 제출은 `You:` chat message로 남기도록 했다.
- 기존 `Character.mesh` runtime player mesh를 제거하고 `assets/textures/character/Character.glb`를 직접 로딩하도록 변경했다.
- `PlayerModelLoader`를 추가해 GLB node, mesh primitive, vertex, UV, index data를 읽고 vertex별 source node index를 보존하도록 했다.
- `PlayerMeshRenderPath`가 GLB node transform을 유지하고, 매 프레임 transform을 적용한 뒤 `1 / 16` scale로 player position에 배치하도록 했다.
- 새 player model은 `Head`, `BodyRoot`, `Arm_L`, `Arm_R`, `Leg_L`, `Leg_R` 같은 named part를 유지해 head rotation과 walking motion에 사용할 수 있게 했다.
- camera yaw와 rendered body yaw를 분리했다.
- `ClientFrame`과 `RendererFrame`에 head yaw/head pitch 값을 추가했다.
- head는 카메라를 즉시 따라가되 상대 yaw를 `-45도..+45도`, pitch를 `-70도..+70도`로 제한하도록 했다.
- camera yaw가 head yaw limit을 넘으면 body yaw를 즉시 보정해 head가 제한 범위 안에 머물도록 했다.
- `Head` node transform에 head yaw/pitch를 적용했다.
- `assets/ui/options.rml`을 추가하고 lobby/pause menu에 `OPTIONS` 버튼을 연결했다.
- options 화면은 기존 RmlUi menu routing을 사용하고, 열린 화면으로 되돌아가도록 했다.
- BGM/SFX volume slider와 percent label을 추가했다.
- lobby에서 options를 열면 lobby 배경을 사용하고, pause에서 열면 반투명 pause overlay를 유지하도록 했다.
- config directory의 `settings.json`에서 `audio.bgmVolume`, `audio.sfxVolume`을 load/save하도록 했다.
- music source gain은 BGM volume을, 모든 SFX playback gain은 SFX volume을 곱하도록 runtime audio volume 적용 경로를 연결했다.
- block data parsing과 runtime block definition에 `alphaBlend`를 추가했다.
- terrain CPU mesh output을 solid subchunk data와 blend subchunk data로 분리해 `alphaMode = "blend"` 블록이 opaque terrain path 밖에서 렌더링되도록 했다.

- 공유 `world::Biome` classifier를 추가해 temperature 5단계, precipitation 5단계, ocean/land groundness band를 사용하도록 확장했다.
- biome debug text를 공유 5단계 classifier 기준으로 바꿨다.
- terrain generation 중 biome 기반 air/underwater surface/subsurface block rule을 적용했다.
- `FrozenOcean`은 해저 block은 sand로 유지하되, sea-level 최상단 water cell을 `ice` block으로 교체하고 더 깊은 water는 유지하도록 했다.

## 결정 사항
- biome은 우선 temperature, precipitation, groundness만 사용해 단순하게 분류한다.
- 바다 biome도 temperature/precipitation table을 사용하되, groundness `0`이면 ocean table, `1`이면 land table을 선택한다.
- chat input은 `Enter`로만 열고, `/` 자체는 명령어 prefix일 뿐 열기 단축키로 쓰지 않는다.
- player model은 GLB node 이름을 기준으로 부위별 transform을 적용한다.
- ice 같은 반투명 블록은 픽셀별 복잡한 투명도보다 block definition의 전체 `alphaBlend` 값을 우선 사용한다.
- 표면 룰은 air surface rule과 underwater surface rule을 분리한다.

## 이슈
- 실제 biome별 장식물 배치와 세부 surface/subsurface rule은 이후 추가 작업이 필요하다.
