# 2026-05-19

## Biome debug
- Added a first-pass biome classifier for diagnostics using only `temperature`, `precipitation`, and `groundness`.
- Temperature and precipitation use 3 bands each. Groundness uses `0` for ocean when `GND < 0` and `1` for land otherwise.
- Added land and ocean 3x3 biome tables and display the result under the climate line as `BIOME: T[n] P[n] GND[n] - BiomeName`.

## HUD chat input
- Added an RmlUi chat panel to the HUD at the lower-left of the game screen.
- Enter opens the chat input in game. Enter with empty text closes it, and Enter with text submits it to the local chat log.
- Escape closes the chat input without submitting. `/` no longer has any special open behavior; submitted slash-prefixed text is only tagged as command text for now.
- After submission, chat history remains on the HUD as text-only transparent overlay while the input box is hidden.
- While chat is open, game movement, hotbar scroll, block break/place, and gameplay hotkeys are consumed by the UI path instead of gameplay.
- The chat input uses RmlUi text input, key modifiers, and GLFW clipboard integration so selection and copy/paste shortcuts such as Ctrl+A/C/V stay on the text control.

## Options screen
- Added `assets/ui/options.rml` and wired an `OPTIONS` button into both the lobby and pause menus.
- Options uses the shared RmlUi menu routing with `menuOverlayMode == 6`, returning to the screen that opened it.
- Added BGM and SFX volume controls using RmlUi range sliders and percent labels.
- Options uses the lobby-style background when opened from the lobby, and a translucent pause overlay when opened from pause.
- Added `settings.json` loading/saving under the config directory with `audio.bgmVolume` and `audio.sfxVolume`.
- Added runtime audio volume application so music source gain uses BGM volume and all SFX playback gain is multiplied by SFX volume.
