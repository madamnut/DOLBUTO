# Groundness 옥타브별 간격 · 2026-09-25

AI 작업 컨텍스트. 사용자 범위한정후실시로구현·빌드·패키징승인.

## 구성

- NoiseSettings.spacings를추가했지만비어있지않은배열은Groundness에서만허용. 각원소4..131072의유한float,원소수=octaves(1..16). 간격은단조/2배관계/2의거듭제곱을요구하지않는다. 다른노이즈/워핑/shape는기존규칙.
- schema8에서groundness.spacings가필수. 기존spacing_log2는구형이행용필드로보존하되명시적배열이우선한다. v1..7은유효성확인후ldexp(1,spacing_log2-i)로배열을채운다. 현재schema7의패턴을정확히유지하며더오래된Perlin시대설정은직전Simplex전환정책을따른다.
- octave_spacings 공통함수로생성기·저장·미리보기이행을공유. Simplex각옥타브의SetScale만직접간격으로설정. 토러스/워핑/시드/가중치정규화/3D밀도/스플라인변경없음.
- F8와별도미리보기는config내Groundness객체인지확인해독립간격UI를표시. 워핑은individual weights여도독립간격이되지않는다. 웹편집기는Groundness에만입력행을추가. 새겹은직전간격절반(최소4),가중치0. 최대16이며기존간격지수에의해수가줄어들지않는다.
- 개별옥타브미리보기: 간격지수를index만큼빼던처리대신선택한spacings[index]를유지한단일옥타브설정을만든다. seed_offset+index/weight기여도/워핑은기존과같다.
- assets/worldgen/default.json은기존기본간격을명시한schema8. out/Sandbox/worldgen.json과settings.json은바이트보존하며읽기/빌드로자동저장하지않는다. 실행중게임/편집기는재시작해야새바이너리를사용한다.

## 확인

- 일반자동테스트/CTest추가없음. 명시적인격리편집기 --no-browser API확인. 사용자UI조작/CU/합성입력없음.
- 기존/새편집기동일사용자schema7파일로실행. 범위0..16384와0..131072,64²해상도,12지도씩총24개전체버퍼(헤더/float)가바이트동일.
- 현재사용자Groundness4옥타브간격4096/2048/1024/512. 개별4옥타브×원신호/기여분=8지도도전후바이트동일.
- 간격4096/768.5/320.25/512의혼합구성: 결과변경확인. 옥타브별기여분합과전체합성의최대오차1.2012606021016836e-7. 실제공유C++생성기로계산. 다른기본신호6종은동일. 전체월드X/Z양끝정확일치. 양끝값비교만으로모든연속미분을증명하는검사는아니며좌표매핑자체는변경하지않았다.
- 16옥타브및간격4/131072/소수/비정렬배열허용·마지막옥타브보기확인. 잘못된범위/배열길이/다른6노이즈·워핑배열총11설정을거부. 격리초안/확정저장후배열일치확인.
