# 기본 바이옴 — AI 컨텍스트

사용자가 바다/강/육지3종만 우선분류하고F3표시하는제안에 `실시`로승인. 온도·강수량은기존9단계진단을유지하되바이옴선택에사용하지않는다. 루트README는사용자안내,이문서는후속구현맥락이다.

## 공용 규칙

src/world/biome.hpp의Biome {ocean,river,land}, surface_biome(G,E,W). 유한한현재생성기의워핑후Groundness/Smoothness/Weirdness를받는순수함수다. 전역공유변경상태·랜덤·독립노이즈가없다. 후속표면/식생은같은함수와같은입력으로조회할수있다. 이번에는컬럼별별도저장/매블록바이옴배열을추가하지않으며F3가기존10Hz표본에서분류한다.

우선순위와경계:

1. G<−.19:바다. 깊은바다등은모두여기로합침.
2. 나머지에서|W|>.05:육지.
3. 중앙계곡|W|≤.05에서 E<−.375: G<.03(해안/가까운내륙)만강,나머지육지.
4. E≥−.375이고E<.55:강.
5. E≥.55: G<−.11(해안)만강,내륙육지.

G/E경계는상위구간,중앙계곡끝±.05는포함한다. NaN/Inf는함수계약밖이며F3호출부에서판정불가표시한다. 입력이−1..1범위밖이어도바다/육지등경계규칙을그대로확장한다.

## 원본과 차이

ref/MCP-Reborn/src/main/java/net/minecraft/world/level/biome/OverworldBiomeBuilder.java의oceanContinentalness(−.455..−.19),coast(−.19..−.11),nearInland(−.11...03),erosions구간및addValleys(W−.05...05)를근거로했다. 원본의원시Weirdness중앙구간은PV약−1..−.85에해당한다. PV만상한검사하면|W|>1인원시노이즈의접힌꼬리까지강으로분류할수있어|W|로중앙계곡을명시한다. 노이즈계산/스플라인에는변경없다.

원본은6차원파라미터영역최근접검색,기후별강/얼어붙은강/늪/맹그로브/버섯섬/해안예외가있다. 이번분류는그시스템의완전이식이아니다. 아주완만한내륙의늪·얼어붙은강예외는온도를사용하지않도록일단육지로통일. 바다입력의극단영역도버섯섬특례없이바다로분류. 경계양자화와다른범위에대한최근접경쟁은없고명시한비교규칙으로결정한다.

같은XZ에서는플레이어높이/블록편집/유체흐름에따라분류가바뀌지않는다. 실제수면/육지와일대일대응을보장하지않으며사용자가스플라인을바꿔도경계임계값은고정이다. 이번작업은기존지형을깎거나물을채우지않고표면블록/눈·얼음/나무·풀/기후세분화도추가하지않는다. 표면룰연결은별도합의후진행한다.
