# 용암 · 2026-09-25

AI 컨텍스트. 사용자와 물/용암 표면 출렁임 OFF, 동일 텍스처의 원본 방향 및 약30° 방향 두 겹 스크롤, 공용20TPS 안에서 용암만5틱마다 갱신을 합의하고 `ㅇㅋ 실시`로 적용·Release빌드·패키징 승인.

## 최신: 용암 초당1회 갱신

Release 빌드·패키징 완료. 빌드/배포 실행파일 해시 일치, 사용자 settings/worldgen 해시 보존. 공용 카운터와 대기 활성셀 보존 경로를 소스로 확인했으며 이번 변경의 게임 실행 확인은 하지 않았다.

사용자 `실시`로 용암의 공용 틱 조건을 tick_%20==0으로 변경했다. 전체20TPS/물매틱 유지. 활성 용암은 다음20틱주기까지 대기하며 첫설치대기는공용틱위상에따라0~19틱이다. 갱신당이동량256/16과텍스처스크롤속도는유지한다. 아래5틱/4TPS및관련진단은이전구현이력이다.

## 원본 한 장, 이동 방향30°

Release 셰이더 컴파일·패키징 완료. 빌드/배포 world.frag.spv 해시 일치, settings.json/worldgen.json 작업 전후 해시 동일. 이번 수정은 소스 검토와 컴파일로 확인했고 게임 실행/외관 검증은 별도로 하지 않았다.

후속 사용자 요청과 `실시`로 회전한 두 번째 레이어 및 혼합을 제거했다. 원본 이미지 방향은 유지하고 `plane - (cos30°,sin30°) × 0.018 × 시간`으로 무늬만 이동한다. 속도는 기존 첫 레이어와 같은0.018타일/초, 텍스처 샘플은두번에서한번으로감소. 세계좌표기반정수타일반복을유지하므로순환경계도그대로이어진다. 아래두겹기록은초기구현이력이며발광수식·조명·유체틱·설치규칙은유지한다.

## 틱과 저장

- 물리 루프/타이머를 분리하지 않는다. main의 기존 advance_fluids 호출 및50ms accumulator를 유지한다. FluidSimulation::tick은 매 틱 호출되고 기존 tick_를 사용하여 용암만 tick_%5==0에서 이동한다. 중간틱의 용암 활성 셀은 active_에 보존한다. 신규 월드/재생성 때 기존 FluidSimulation 초기화가 주기도 초기화한다.
- 물은 매틱, 용암은5틱마다 아래최대256/수평4면총16. 이는 사용자의4TPS 정정 후 제안된 이동량이며, 이전 제안64/2는 적용하지 않는다. 첫 설치 직후 대기시간은 공용 틱 위상에 따라0~4틱이다. 프레임 지연시 기존 accumulator100ms 상한으로 실제시간상의4TPS는 느려질 수 있다.
- FluidKind::lava와 호환 조회용 Block::lava를 추가한다. Fluid2bytes/양256/표시16단계/세션 덮어쓰기·재로드 유지. 물과 용암은 다른 종류의 셀에 들어가지 않는다. 빈칸에 동시 예약할 때 먼저 예약된 종류만 들어가며, 재료별 양을 보존한다. 접촉 반응/돌·흑요석 생성/압력/무한수원 규칙은 미합의라 추가하지 않았다.
- 핫바7번 용암을 추가한다. 기존 물과 같은 고체면 인접칸 설치·한 번256까지 채우기이며, 다른 유체 덮어쓰기는 거부한다. 유체에 고체 설치 거부/몸 겹침 허용 유지. 8~0 빈칸. 자연생성/피해/연소/버킷/용암 속 전용 안개는 추가하지 않았다.

## 메시·표현·조명

- 기존 assets/textures/fluid/lava.png(32×32)를 원본 그대로 사용한다. 다운로드/이미지 편집 없이 월드 아틀라스와 핫바에서 공유한다. 셰이더에서 동일 이미지 두 겹: 첫 UV 원본, 둘째 행렬(113512,65536;-65536,113512)/131072로 약30° 회전. X/Z 월드 한 주기마다 정수 타일 수가 되며 일반 청크 경계는 세계 좌표로 연결한다. 속도(0.018,0),(-0.006,0.011) 타일/초, 혼합비38%가 초기값이다. 수평면XZ/수직면해당수평축과-Y를 사용한다.
- 표면 정점의 시간 변위는 없다. 같은 유체끼리 기존 한 단계 높이 연결을 적용하고, 물/용암 접점의 연결 성분은 평탄한 모서리를 유지한다. 물은 투명 경로, 용암은 불투명 경로로 깊이/그림자/물 반사 입력에 참여한다. 물 효과 설정은 용암 재질을 끄지 않는다.
- PackedFace4bytes 유지. 기본material5=물/7=용암. 기존 흰색 발광 블록은 base material0+기존 예약bit27로 구분하고 shader에서atlas tile8로 해독한다. 고체 AO는 그대로, 두 유체는 동일 꼭짓점 높이 ABI를 쓴다. 흙0과 발광8은 bit27 유무로 구분된다. 아틀라스9장/288×32.
- 용암 자체는 방향광/AO와 무관하게 텍스처의 선형색×(1.1+3×명도)로 HDR 발광한다. 밝은 무늬가 블룸에 반영된다. 이는 합의된 두 겹 텍스처용 초기 조정이며 Complementary 용암 수식 전체의 동일 이식은 아니다.
- 주변 인공광15 및 불투명 조명 차폐를 연결했다. 물리 충돌 is_solid와 광학 차폐를 분리한다. 조명은 기존 단일 밝기 채널/공통 블록광 색이므로 용암 전용 RGB 전파를 추가한 것은 아니다. 생성 로컬·경계 연결·편집 증분·삭제 및 light halo occluder에 유체 종류를 반영한다. 카메라 수중 효과는 물에만 적용한다.
