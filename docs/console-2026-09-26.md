# 인게임 콘솔 · 2026-09-26

AI 컨텍스트. Enter 콘솔과 제안한 네 명령/기록/입력 차단에 사용자가 위치를 화면 아래에서 약1/3로 정정 후 `실시` 승인.

- `ui/game_console.*`의 GameConsole. ImGui 창 하단을 화면 높이2/3에 고정하며 입력칸은 그 안의 맨 아래, 기록은 위쪽 스크롤 영역. 최대폭1000/높이320, 작은 화면에서는 가용폭/화면높이 절반으로 제한. 기존 NotoSansKR/ImGui Vulkan 경로 사용.
- Enter/키패드Enter로 플레이 중에만 열기. 옵션/F8에서는 열지 않는다. Enter실행, 공백만 있으면닫기, Esc닫기(옵션으로이중전달하지않음). 위/아래로100개명령기록 탐색, 원래작성중입력복원. 출력200줄/입력511bytes한도, 실행세션만보관.
- main SDL 라우팅에서 열기 Enter를 ImGui에 전달하지 않으며 즉시 상대마우스해제/이동입력초기화. 콘솔중 마우스·키보드는 ImGui만 처리하고 RmlUi/월드단축키에전달하지않음. 닫기후캡처전환프레임은이동하지않음. 포커스상실/메뉴전환시닫는다. 콘솔에서블록편집·카메라회전·핫바·시간키·구름키차단.
- UI draw는명령을보관만하고다음프레임 begin_frame 전 execute_pending에서적용. GPU기록중월드변경없음. 셸/파일실행/외부명령없음. 기존 F8와같이 이동경로에있는시각진행도멈추지만별도유체갱신은유지하며새로운일시정지규칙은추가하지않음.
- `/help`: 네명령과사용법. `/time`은조회, `/time HH:MM`은00:00..23:59 현재날짜유지·초기화분의정수틱지정. 잘못된시각/초과인수는변경없이오류. TAA이력무효화.
- `/tp`는실제플레이어발좌표조회, `/tp x y z`는절대소수좌표이동. 유한값, X/Z ±1e9·Y0..8192 허용. X/Z131072순환. 몸/카메라보간위치·수직속도·누산시간·선택대상·입력상태를리셋하고카메라각도/시점모드/이동모드는보존. TAA이력무효화. 기존stream이새중심을따름. 빈공간자동탐색/미리로딩대기없음; 고체속좌표도명시한그대로이동.
- `/gamemode`조회, `/gamemode walk|fly`변경. 기존더블스페이스와 WorldView::set_movement_mode를공유하여수직속도/접지/입력리셋규칙유지. 시간·좌표·모드는파일자동저장없음.
- 일반자동테스트/합성입력/컴퓨터유즈는추가하지않음. 콘솔실제키입력/화면배치는직접플레이검증하지않음.
- 포맷검사/Release빌드·패키징성공. 배포실행파일/README해시일치, settings.json/worldgen.json 작업전후SHA256동일. 이번에는실제게임을실행하지않음.
