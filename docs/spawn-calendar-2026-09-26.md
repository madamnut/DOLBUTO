## 스폰

- `world/spawn.*`의 find_land_spawn. 각 후보는 X 정수0..131071 균등, 두 위도대는각50%, Z 정수[28672,36864) 또는[94208,102400)에서균등 선택. 후보가 부적합하면 X/Z/대역을 다시 추첨하므로 최종 성공 비율은 실제 육지 분포에 좌우된다. 실제 온도/강수 노이즈 필터는 없다. 위치는 블록중심X+.5/Z+.5.
- terrain generate_tile의 실제 최상단 고체 surface_y+1을 발 높이로 사용. 발 높이192이상510이하이며, 같은 생성기의 실제 청크를 만들어 발밑높이1고체/몸체 두칸air/셋 모두유체없음을확인한다. .7×.7 몸체는선택한1×1기둥안에들어간다. 이전높이추정상한+28 공중배치는일반시작에쓰지않는다.
- terrain seed와 별개인 random_device/monotonic clock 기반 RNG를 새 WorldView마다 사용. 땅생성 규칙/사용자 worldgen은 바꾸지 않는다. 첫발높이/카메라눈높이1.6/이전·보간위치를같이초기화한다. 후속 사용자 시작 플라이 금지 요청과 `실시`에 따라 일반 새 월드는 걷기 모드·grounded=true로 시작한다. 스페이스 두 번 전환은 유지하고 명시적 성능 프로필만 기존 공중·플라이 조건을 유지한다.
- 512회 상한. 실패하면 분명한 생성설정 오류를 보고하고 초기화를 중단한다. 무한재시도·물위강제배치·새땅생성을하지않는다. 특수한전해양/전공기/상단가득찬설정은스폰을찾지못할수있다. 탐색은초기화에서동기실행하며이후프레임반복비용없음.
- 명시적 --profile-world/--profile-gpu 경로는 기존origin/공중카메라를유지해기존성능비교조건이무작위로바뀌지않는다. 일반 --world/싱글플레이에는새스폰적용. F8재생성은기존위치·높이·각도·시간보존이며재추첨하지않는다. 시작메뉴로돌아갔다가같은세션의월드를다시열어도그대로다.
