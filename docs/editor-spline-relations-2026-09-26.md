# 웹 스플라인 관계 편집 — 2026-09-26

AI용 작업 컨텍스트. 사용자 승인: 관계를 볼 수 없다는 지적 → 연결 트리/제어점 표/경로/미리보기 제안 → `실시`.

## 구조

- assets/editor/app.js: 기존 schema10 값 소유 중첩 tree를 직접 탐색한다. 별도의 이름/연결 ID/schema는 추가하지 않는다. 상위 제어점의 value가 숫자인지 객체인지 표와 트리에 구분한다.
- 왼쪽 Offset/Factor/Jaggedness 항목 중 선택한 항목에 연결 트리를 표시. 하위 details는 열 때 DOM을 생성하여 최대16384노드 전체를 최초 렌더하지 않는다. 열린 상태는 종류+인덱스경로로 세션 내 유지하며 현재 경로의 조상을 펼친다. 선택 항목을 트리 스크롤 내 보이게 한다.
- 가운데 breadcrumb는 `Offset → GND 0.25 → Smoothness ...` 형태. 제어점 경로이며 입력 구간의 배타적 분기를 뜻하지 않는다는 설명을 표시한다. 원본 저장 구조에는 beachSpline/lowSpline 같은 이름이 없어 추정 명칭은 넣지 않는다.
- 제어점 표: 위치, 고정 숫자 또는 하위 곡선 열기, 접선, 삭제. 숫자를 곡선으로 바꾸기는 해당 자식으로 들어가 입력축 선택. 기존 추가/삭제/곡선 축 교체/전체 복사·붙여넣기/원본 복원 유지. 하위 트리 삭제·교체는 확인한다.
- 입력 위치[-2,2], 인접점 간격0.00011 이상, 값·기울기[-64,64]를 입력 단계에서 검사. 서버의 실제 검증(간격0.0001, 깊이8,64점,전체노드예산)은 그대로 최종 권위다. 제어점 추가는 가장 넓은 간격에 왼쪽 출력을 복사하며 형상 변화 가능성을 알린다.
- 오른쪽에 공유 미리보기 GND/E/W 입력, 선택한 규칙 곡선, 전체 규칙 단면, 기존 지도. 고정 입력 변경은 설정/undo/저장 상태에 영향을 주지 않는다. PV는 W에서 유도. 기존 C++ /api/curve 평가를 그대로 사용하며 JS에 생성 공식을 복제하지 않는다.
- 선택 규칙 그래프는 기존 API대로 각 자식 출력을 고정 입력에서 평가한 뒤 선택 노드 축을 그린다. 전체 단면은 선택한 GND/E/W만 바꾸면서 전체 트리를 실제 평가한다. 반복 입력축/PV-W 종속이 있는 경우 둘은 다른 개념이며 UI에서 구분한다. 표의 하위 출력 숫자도 서버 controls 응답에서 표시한다.
- 지도 접기 상태에서도 곡선은 유지. 지도 크게는 지도에 집중하며 곡선을 숨긴다. 1100px 이하에서는 오른쪽 미리보기가 아래로 이동한다. 기존 밝은/어두운 화면을 공유한다.

## 보존 범위

생성기 C++·노이즈·스플라인 평가·프리셋·schema·인게임 F8은 변경하지 않음. 확정/초안 파일 자동 저장 없음. 사용자가 명시적으로 초안/확정 저장할 때 기존 API 사용. 자동테스트/CTest/브라우저·컴퓨터 유즈/합성입력 없음.

## 검증

Release 증분 빌드·전체 패키징, JS 구문 검사, 격리 HTTP 정적 에셋/루트·하위·상수·최종단면/메모리 수정 검증을 완료했다. 사용자 파일 해시 보존과 구체적인 결과는 docs/verification.md에 기록했다. UI 화면의 시각 검증과 입력 실사용은 컴퓨터 유즈 금지에 따라 수행하지 않는다.
