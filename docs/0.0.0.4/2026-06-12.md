# 2026-06-12

## 작업 기록
- `block_model` 슬롯 아이콘 생성을 2.5D 면 합성 방식에서 실제 로컬 3D quad mesh 투영 방식으로 변경했다.
- 새 투영 경로의 X/Z 축 화면 매핑을 기존 슬롯 아이콘 각도와 맞췄다.
- 작은 도가니 액션 이름을 `scoop/pour`에서 `fill/pour`로 변경했다.
- 금속 cast part 1차 완성품을 도가니에 다시 넣으면 같은 금속 용탕으로 재용해되도록 `smelt` 레시피를 추가했다.
- 슬롯 아이콘 생성기에 64x64 depth buffer 기반 소프트웨어 래스터라이저를 적용해 도가니 내부 벽/바닥처럼 복잡한 형상도 자동으로 아이콘에 반영되도록 했다.
- 생성된 슬롯 아이콘은 `assets/textures/item/generated/{item_key}_slot.png` 파일이 이미 있으면 재사용한다.
- 관련 설계 문서의 슬롯 아이콘 렌더링 설명을 현재 구현 기준으로 갱신했다.

## 결정 사항
- 슬롯 아이콘은 프레임마다 렌더링하지 않고 콘텐츠 로딩 단계에서 PNG로 굽고 재사용한다.
- 도가니 같은 특정 형상 예외를 계속 추가하지 않고, 실제 모델 메쉬를 같은 각도로 투영하는 공통 경로를 사용한다.

## 이슈
- 빌드는 사용자가 직접 수행하므로 이번 작업에서는 실행하지 않았다.

## 추가 작업 기록
- 기존 `tar` 아이템을 `wood_tar`로 분리하고, coal coking 부산물용 `coal_tar`와 고온 연료 `coke` 아이템을 추가했다.
- `pyrolysis` processing에서 `coal -> coke + coal_tar x2` 레시피를 추가하고, `requiredHeatLevel = 3`, `requiredTicks = 1200`으로 설정했다.
- item-to-item processing 완료 시 `byproducts` 목록을 별도 드랍 아이템으로 생성하도록 처리했다.
- 일반 fire processing에서도 레시피의 `requiredHeatLevel`을 현재 fire heat level과 비교하도록 연결했다.
