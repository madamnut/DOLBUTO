# 2026-07-03

## 작업 기록
- 1인칭 viewmodel 전용 idle sway와 카메라 회전 관성 모션을 추가했다.
- `ViewmodelMotion`을 `ClientFrame`/`RendererFrame`으로 전달해 빈손과 든 아이템 렌더 경로에서 같은 시각 offset을 사용하도록 했다.
- 3인칭 플레이어 모델, 3인칭 손 아이템, 실제 카메라, raycast, 상호작용 판정에는 viewmodel motion을 적용하지 않았다.
- idle sway와 카메라 회전 관성 수치를 높여 1인칭 손/아이템 움직임이 더 뚜렷하게 보이도록 조정했다.
- 1인칭 손 mesh를 월드 좌표 대신 카메라 상대 viewmodel 좌표로 렌더링하도록 바꿔 먼 좌표에서의 미세 흔들림 가능성을 줄였다.
- 좌클릭 시 1인칭 손/아이템 swing motion을 추가했다. 허공 클릭은 1회만 재생하고, 좌클릭 유지 중 실제 파괴 가능한 블록을 보고 있으면 반복 재생한다.
- 1인칭 viewmodel motion을 단순 위치/회전 offset에서 어깨 offset, 어깨 pivot, 어깨 회전 구조로 바꿨다.
- 빈손과 든 아이템 모두 같은 어깨 pivot 기준으로 idle, 카메라 관성, 좌클릭 swing, 보행 모션을 적용하도록 했다.
- `walkPhase`와 `walkAmount`를 viewmodel motion에 연결해 걷기/달리기/웅크림/엎드림 이동 속도에 따라 1인칭 손/아이템 보행 모션 강도가 달라지도록 했다.
- 1인칭 viewmodel motion의 위치 offset 명칭을 어깨 offset으로 바꾸고, 보행/idle은 회전보다 어깨 위치 이동 비중이 크게 보이도록 튜닝했다.
- 좌클릭 swing motion을 어깨 offset 이동과 어깨 pivot 기준 큰 회전 arc 조합으로 다시 조정했다.
- 좌클릭 swing motion을 단일 `sin` 왕복에서 windup, 반원형 strike, 직선 recover 구간을 가진 pose curve로 교체했다.
- strike 구간에서 `sin/cos` 기반 전방/하강 offset과 어깨 pivot 기준 X 회전을 적용해 손/아이템이 반원 궤도로 내려찍히도록 조정했다.
- `ViewmodelMotion`의 어깨 pivot 기준 회전과 손/아이템 자체 local 회전을 분리했다.
- 스윙은 local 회전을 추가하지 않고 어깨 pivot 기준 회전과 전방/하강 어깨 offset으로 손/아이템 전체가 통째로 도는 방식으로 다시 조정했다.
- 스윙 strike 구간을 `sin/cos` 기반 반원 궤도로 바꾸고, recover 구간은 직선으로 원위치에 감쇠하도록 조정했다.
- 스윙 strike의 전방 반지름과 측면 이동량을 키워 휘두르기 시작점과 끝점 사이 거리를 더 벌렸다.
- 보행 viewmodel motion을 어깨 offset이 U자형 궤도에 가깝게 움직이도록 바꿨다.
- 카메라 yaw/pitch 회전 관성의 반응 강도와 최대치를 높이고 복귀 속도를 낮춰 손/아이템이 더 늦게 따라오도록 조정했다.
- 하강 중에는 손/아이템이 화면상 위로 서서히 떠오르고, 착지 순간에는 아래로 짧게 눌렸다가 복귀하는 낙하/착지 viewmodel motion을 추가했다.
- 착지 시 fall lift가 바로 사라지지 않도록 복귀 속도를 낮추고, landing kick은 target을 빠르게 따라간 뒤 target이 감쇠하는 방식으로 바꿨다.
- 낙하 중 손/아이템이 위로 떠오르는 수렴 속도를 낮춰 긴 낙하에서 천천히 최대 높이에 가까워지도록 조정했다.
- 가이드의 아이템 획득 완료 판정을 과거 관찰 아이템 목록 방식에서 획득 시점 기반 진행도 방식으로 바꿨다.
- 인벤토리/오프핸드의 아이템 key별 총량을 이전 프레임과 비교해 수량이 증가한 key만 획득 이벤트로 보고, 현재 클리어 가능한 가이드만 내부 진행도를 갱신하도록 했다.
- `DOLBUTO!`처럼 여러 아이템을 요구하는 가이드는 가이드별 획득 key 진행도를 저장하고, 요구 key가 모두 채워졌을 때 완료되도록 했다.

## 결정 사항
- Luanti의 `arm_inertia`처럼 세부 수치는 코드 상수로 관리하고, 현재 단계에서는 `config/viewmodel.json`에 motion 설정을 추가하지 않는다.
- 1인칭 손/아이템 보행 모션도 별도 입력 상태가 아니라 실제 이동에서 계산된 `walkAmount`를 기준으로 처리한다.
- 1인칭 viewmodel의 보행/idle은 손끝 회전보다 어깨 offset 이동을 우선해 팔 전체가 따라 움직이는 느낌으로 처리한다.
- 낙하 viewmodel motion은 공중 상태 전체가 아니라 수직 속도가 기준값보다 낮은 하강 상태에서만 시작한다.
- 착지 후 낙하 lift는 잔류 감쇠시키고 landing kick은 별도 target으로 처리해 정상 위치로 순간이동하는 느낌을 줄인다.
- 가이드 저장 데이터는 레거시 observed-item 기록을 지원하지 않고, 완료 key 목록과 미완료 가이드별 진행도만 저장한다.

## 이슈
- 빌드는 사용자가 직접 수행한다.
- 3인칭 플레이어 모델이 보이지 않던 문제는 `drawPlayer()`가 1인칭 viewmodel처럼 `cameraPosition` push 값을 0으로 넘기면서 발생했다. 플레이어 모델은 월드 좌표 transform을 쓰므로 실제 렌더 카메라 위치를 push하도록 복구했다.
