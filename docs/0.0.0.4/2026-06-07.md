## 작업 기록

- 구름 렌더링을 기존 procedural value noise 방식에서 cloud noise texture 기반 raymarch 방식으로 재작성했다.
- `assets/textures/cloud/noise.png`를 임시 구름 noise source로 추가하고, cloud pass에서 전용 linear repeat sampler로 샘플링하도록 연결했다.
- cloud shader는 큰 형태, breakup, detail noise를 여러 스케일로 합성하고 높이 프로파일, 거리 fade, 하늘색 혼합, 태양 방향 cheap self-shadow를 적용하도록 바꿨다.
- 구름 slab 범위를 `Y=520..640`으로 조정해 기존보다 얇은 렌더 전용 구름층으로 처리한다.

## 결정 사항

- ComplementaryUnbound shader 코드는 직접 복사하지 않고, 임시 noise texture만 asset으로 복사해 DOLBUTO용 cloud shader를 새로 작성한다.
- 빌드와 런타임 확인은 기존 지침대로 사용자가 직접 수행한다.

## 이슈

- `assets/textures/cloud/noise.png`는 임시 reference texture이므로 최종적으로 DOLBUTO 자체 noise texture로 교체해야 한다.

## 작업 기록
- cloud pipeline layout에 texture descriptor set layout이 누락되어 cloud pass에서 descriptor bind 이후 push constant 기록 중 드라이버 crash가 발생하던 문제를 수정했다.
- 잘못 sky pipeline layout에 들어갔던 descriptor set layout 연결을 제거하고, cloud pipeline layout에만 연결했다.
