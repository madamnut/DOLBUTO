## 결정 사항
- 합성 아이템 레이어 텍스처는 아이템 텍스처 하위의 `composites` 경로에 둔다.
- 합성 레이어 텍스처 파일명도 기존 아이템 텍스처와 같은 소문자 `snake_case` 규칙을 따른다.
- 합성 레이어 variant suffix는 현재 `short`, `default`, `long`을 사용한다.

## 이슈
- 합성 레이어 텍스처를 실제 아이템 렌더링에 사용하는 로더와 렌더 경로는 아직 구현하지 않았다.
