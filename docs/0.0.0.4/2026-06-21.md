## 작업 기록
- 석기 원재료 크기 3종용 `small_stone.png`, `stone.png`, `large_stone.png` 아이템 스프라이트를 생성했다.
- 세 스프라이트를 기존 석기 픽셀아트 스타일에 맞추고, 투명 배경의 `32 x 32` RGBA PNG로 저장했다.
- 확정 전 자산이 활성 아이템 텍스처로 취급되지 않도록 세 파일을 `assets/textures/AIGenerated/`로 옮겼다.
- `large_stone.png`를 작은 돌과 중간 돌의 팔레트, 명암, 픽셀 밀도에 맞춘 독립적인 큰 돌 형상으로 다시 제작했다.
- 기존 석기 스프라이트를 참조하지 않고 돌 크기 3종을 신규 픽셀아트 스타일의 한 세트로 전부 다시 생성했다.
- 작은 돌은 주먹 하나, 중간 돌은 주먹 2~3개, 큰 돌은 사람 머리 정도라는 실제 크기 기준으로 세 스프라이트를 처음부터 다시 제작했다.
- 고해상도 미세 묘사를 축소하는 대신 `32 x 32` 논리 픽셀 그리드와 큰 단색 픽셀 군집을 기준으로 세 스프라이트를 다시 생성했다.
- `large_stone.glb`를 기존 `stone`과 같은 `prop` 형식의 블록 ID `20002`로 등록하고 `rock` 텍스처를 공유하도록 했다.
- grass 표면 생성 난수에서 plant 구간 상위 4개를 분리해 `large_stone`이 `148 ~ 151`, plant가 `0 ~ 147`을 사용하도록 변경했다.
- `stone.glb`와 `large_stone.glb`의 UV를 일반 블록과 같은 `1블록 = 32px` 텍셀 밀도 기준으로 조정했다.
- 지면 돌 소품의 실제 역할에 맞춰 `stone` 모델/블록 이름을 `stone_pile`로, `large_stone` 모델/블록 이름을 `large_stone_pile`로 변경했다.
- `small_stone` 파생 초안인 `stone_blade`, `stone_scraper`, `stone_point` 3종의 임시 `32 x 32` RGBA 스프라이트를 `assets/textures/AIGenerated/`에 생성했다.
- `stone_blade`, `stone_scraper`, `stone_point` 생성 원본에서 배경만 투명화한 원본 크기 임시 PNG도 별도로 저장했다.
- `stone` 파생 초안인 `stone_chopper`, `stone_maul`, `stone_pestle` 3종의 생성 원본에서 배경만 투명화한 원본 크기 임시 PNG를 저장했다.
- `large_stone` 파생 초안인 `stone_anvil`, `stone_mortar` 2종의 생성 원본에서 배경만 투명화한 원본 크기 임시 PNG를 저장했다.
- 기존 `stone_mortar` 임시 파일은 유지하고, 낮은 자연석에 얕은 홈이 있는 방향의 `stone_mortar_shallow_transparent_raw.png` 재시도본을 추가했다.
- `stone_anvil.glb`와 `stone_mortar.glb`의 쿼드별 UV를 일반 블록과 같은 `1블록 = 32px` 텍셀 밀도 기준으로 조정했다.

## 결정 사항
- 자연 상태의 휴대 가능한 돌은 작은 돌, 돌, 큰 돌의 세 크기로 구분할 예정이다.
- 작은 돌의 1차 파생 초안은 `stone_blade`, `stone_scraper`, `stone_point` 3종으로 둔다.
- 중간 돌의 1차 파생 초안은 `stone_chopper`, `stone_maul`, `stone_pestle` 3종으로 둔다.
- 큰 돌의 1차 파생 초안은 `stone_anvil`, `stone_mortar` 2종으로 둔다.
- 이번 작업은 스프라이트 준비만 포함하며 아이템 데이터 등록과 게임 로직은 포함하지 않는다.
- AI 생성 텍스처는 확정 전까지 `assets/textures/AIGenerated/`에 임시 보관하고, 작업 완료 후 실제 텍스처 폴더로 옮긴다.
