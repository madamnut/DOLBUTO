# 2026-06-22

- 지형 메쉬 업로드 경로에서 청크 설치 시 그래픽 큐 전체 idle을 기다리지 않도록 terrain 전용 async one-time submit 경로를 추가했다. staging buffer, command buffer, fence는 pending upload로 보관한 뒤 fence 완료 시 정리하고, retire된 청크가 아직 pending upload destination buffer를 포함하면 GPU 리소스 파괴를 보류한다.
- 전체 청크 메쉬 설치에서 solid, blend, fluid 업로드를 하나의 staging buffer와 command buffer submit으로 묶어 청크당 upload submit 수를 줄였다.
- terrain upload staging buffer를 fence 완료 후 free pool로 반환해 다음 업로드에서 재사용하도록 했다. 전체 terrain render data 파괴 시 pending upload를 기다린 뒤 free staging buffer도 함께 파괴한다.
- terrain device-local vertex buffer도 청크 교체/retire 시 바로 파괴하지 않고 크기 기준 free pool로 반환해 다음 terrain mesh 업로드에서 재사용하도록 했다.
- terrain vertex descriptor set도 청크 교체/retire 시 free list로 반환하고, 새 terrain mesh 설치에서 재사용한 뒤 storage buffer binding만 갱신하도록 했다.
- 새로 설치되는 전체 청크 메쉬가 0.5초 동안 페이드인하도록 했다. 완료된 solid 청크는 기존 opaque pipeline을 사용하고, 페이드 중인 solid 청크는 depth write가 켜진 별도 single-pass alpha blend pipeline으로 한 번만 그린다. blend 지형과 유체는 기존 alpha에 페이드 진행률을 적용한다.
- 석기 재료 체계를 `small_stone`, `stone`, `large_stone` 3단계로 정리하고 `rock_chunk`, `stone_shard`, `stone_flake`, `stone_pounder` 데이터 참조를 제거했다.
- `small_stone + chip`은 `stone_blade`, `stone_scraper`, `stone_point` 후보를 만들고, `stone + chip`은 `stone_chopper`, `stone_maul`, `stone_pestle` 후보를 만들며, `large_stone + chip`은 `stone_anvil`, `stone_mortar` 후보를 만든다.
- `rock`과 광물 블록 드랍을 큰 돌/중간 돌/작은 돌 조합으로 변경하고, `stone_pile`과 `large_stone_pile` 드랍도 새 돌 크기 체계에 맞췄다.
- `stone_anvil`, `stone_mortar`를 설치 가능한 `prop` 블록과 `block_model` 아이템으로 추가했다.
- `block_model` 슬롯 아이콘 생성이 `prop` 블록을 큐브로 대체하지 않고 로드된 `.dpm` prop mesh를 아이소메트릭 투영하도록 변경했다.
- 교체된 기존 석기 텍스처는 `assets/legacy/textures/item/`로 이동하고, 새 32x32 석기 스프라이트를 `assets/textures/item/`에 배치했다.
- 돌/석기 계열 아이템은 모두 `stackSize = 1`로 정리하고, `stone_anvil`, `stone_mortar`를 제외한 돌/석기 계열에 내구도 64와 내구도 슬롯 게이지를 부여했다.
- 설치된 `stone_anvil`, `stone_mortar`는 prop `.dpm` 모델 bounds 기반 AABB 충돌을 사용하도록 하고, 해당 아이템의 드랍/손 렌더링도 prop mesh를 사용하도록 변경했다. 드랍 아이템 물리 AABB는 기존 `block_model` 공통값을 유지한다.
