## 작업 기록
- scene color와 scene depth를 입력으로 쓰는 SSAO scene-space post pass를 추가하고, 결과를 별도 post scene color target에 기록한 뒤 viewmodel, water blur, 최종 presentation이 이를 사용하도록 연결했다.
- SSAO shader에 sky/depth 제외, 원거리 fade, local depth contrast 기반 강도 조절, 큰 depth discontinuity의 silhouette halo 억제를 추가해 접촉부 보강 위주로 보이도록 다듬었다.
- SSAO를 raw factor 생성, depth-aware bilateral blur, scene color apply의 3단계로 분리해 AO만 흐리게 만들고 scene color 자체는 흐리지 않도록 변경했다.
- 물 표면 shader를 Complementary식 색/거리/Fresnel 기반 합성으로 바꾸고, 물속 presentation overlay의 blur/tint 기본값과 색을 더 짙은 underwater fog 느낌으로 재조정했다.
- 갓레이/볼류메트릭 라이트 경로를 제거했다. `RendererFrameLoop`의 god ray 호출, god ray pipeline/layout/descriptor/resource, full-res raw/history target, 관련 framebuffer, CMake shader 항목과 shader 파일을 삭제했다.
- 그림자 경로는 유지했다. shadow map, terrain/player shadow pass, terrain shadow sampling, shadow distortion/PCF는 그대로 남겼다.
- 태양/달/불 블룸이 약해지거나 사라져 보이는 문제를 보정하기 위해 `sprite_scene.frag`의 천체 bloom source 출력과 `terrain_lit.frag`/`terrain.frag`의 fire bloom source 출력을 HDR emissive 값으로 강화했다.
- `sprite_scene.frag`, `terrain_lit.frag`, `terrain.frag`를 `glslangValidator -V`로 검증했다.
- 태양/달 screen-space sprite 투영에서 세로 좌표를 반전했던 변경을 되돌렸다.
- 그림자와 갓레이의 광원 방향 산식은 유지하고, `ScreenPresentation::projectSkyDirection`의 화면 Y 투영은 카메라 `up` dot 값을 그대로 사용하도록 복구했다.
