# 2026-06-30

## 작업 기록
- Added Guide completion notifications to the HUD RML layer.
- Added `notificationBG.png` and `notificationFG.png` usage through the `guide-notifications` HUD container.
- Added a Guide notification queue in `GameClient`.
- Guide notifications slide in from the right, stack upward, and only the bottom notification starts its 2 second hold timer.
- The bottom notification exits downward, while notifications above it follow the current lower notification position.
- Renamed the initial Guide entries to achievement-style names.
- Merged the three stone pickup Guide entries into `gather_stones` / `DOLBUTO!`, which requires `small_stone`, `stone`, and `large_stone`.
- Added the plant branch: `Touch Grass`, `Scrape the Surface`, and `String Theory`.
- Added persisted observed Guide item keys so multi-item Guide steps do not require all items to remain in inventory at the same time.
- Added the wood-to-workbench Guide branch: `Timber!`, `Bare Wood`, `Woof!`, and `Table Manners`.
- Connected wood Guide steps to their required stone tools: chopper for logs, scraper for bark stripping, and blade for workbench carving.
- Extended the plant twine Guide branch with `Long Story` for `long_plant_twine` and `Cut Short` for `short_plant_twine`.
- Added player footstep SFX playback from `assets/audio/sfx/walk`.
- Footsteps now choose a random walk clip and play when grounded horizontal movement accumulates `1.8` blocks.
- Footstep SFX uses gain `0.8` before the global SFX volume is applied.

## 결정 사항
- Guide notification animation state is owned by `GameClient`, and generated RML is pushed to `UiSystem` every frame.
- Notification sprites use the same 4x scaling convention as the existing player UI sprites.
- Guide item completion checks use observed item keys, not only currently held items.
- Block-model items can use representative block textures as Guide icons when they do not have dedicated item sprites.
- Short plant twine Guide progression depends on the blade step because the recipe uses the `cut` action.
- Footstep timing is distance-based instead of timer-based, using a `1.8` block movement interval.
