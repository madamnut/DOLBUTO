- 런타임 생성 cloud texture는 2D extra-large/weather noise, 2D height mask, 3D large noise, 3D medium noise, 3D small noise, 3D curl noise로 나뉜다.
- cloud shader descriptor layout을 별도로 추가해 6개 combined image sampler를 한 descriptor set으로 bind한다.
- low-res cloud raymarch pipeline은 새 cloud descriptor layout을 사용하고, scene 합성용 cloud upscale pipeline은 기존 단일 texture descriptor layout을 쓰도록 pipeline layout을 분리했다.
- `cloud.frag`의 density 계산은 height mask, extra-large weather mask, curl distortion, large base shape, medium breakup, small erosion 순서로 재작성했다.
- 기존 1/4 픽셀 수 low-res cloud pass, scene pass bilinear upscale, cloud slab entry depth 기반 합성, 고정 screen-space jitter, `1.0 - cloudCoverage` threshold 규칙은 유지했다.

## 추가 작업 2
- cloud low-res pass를 color target 1개에서 color/data target 2개를 쓰는 cloud 전용 render pass로 분리했다.
- cloud data target에는 최초 밀도 거리, 최종 진행 거리, 최대 밀도 거리, alpha를 기록하고, cloud upscale shader는 color/data texture를 함께 샘플링한다.
- cloud upscale pipeline layout은 기존 단일 texture descriptor layout 대신 color/data 2-binding composite descriptor layout을 사용하도록 분리했다.
- cloud raymarch를 균일 step에서 adaptive step으로 바꿨다. 빈 공간은 큰 step으로 건너뛰고, 밀도가 잡히면 작은 step으로 줄인다.
- 거리 LOD가 낮을수록 curl, medium, small detail 샘플링을 단계적으로 생략하도록 했다.
- 밀도 샘플마다 self-shadow용 density를 다시 호출하던 `cloudLightAt` 경로를 제거하고, 현재 density와 height 기반 근사 조명으로 바꿨다.
- scene pass 합성은 cloud slab 입구가 아니라 cloud data의 최초 밀도 거리 기준으로 `gl_FragDepth`를 출력한다.
- SunshineClouds2식 full scene depth prepass 기반 raymarch 조기 종료는 아직 미포함이다. 현재 렌더 순서에서는 terrain depth가 cloud low-res pass 이후에 만들어지므로 scene pass 재배치가 필요하다.

## 작업 기록
- 구름 shader의 밀도장을 큰 shape 확인용 fake 3D noise로 단순화했다.
- 기존 2D noise의 Y 대각 오프셋 샘플링을 제거하고, Y 좌표를 가상 slice index로 사용하는 slice 보간 방식으로 바꿨다.
- 중간 breakup, 작은 detail erosion, 저가 self-shadow는 1차 shape 확인을 위해 제거하고 단순 상단 조명 근사만 남겼다.
- SunshineClouds2 구조 분석 결과를 바탕으로 기존 2D/fake slice 구름 입력을 버리고 런타임 생성 3D volume noise로 교체했다.
- `RendererGpuResources`에 `VK_IMAGE_TYPE_3D`/`VK_IMAGE_VIEW_TYPE_3D` 기반 RGBA 3D texture 생성과 buffer-to-3D-image upload 경로를 추가했다.
- cloud noise volume은 `128 x 128 x 128` 크기로 생성하며 RGBA 채널을 large shape, medium breakup, small erosion, extra-large/weather mask 역할로 나눴다.
- `cloud.frag`는 `sampler3D`를 사용해 한 번의 volume sample에서 구조 채널을 읽고, coverage threshold와 height profile로 density를 계산하도록 바꿨다.
- 구름 raymarch를 swapchain 가로/세로 1/2 크기의 low-res cloud target에 먼저 그리도록 바꿨다.
- `cloud_upscale.frag`를 추가해 low-res cloud texture를 scene pass에서 bilinear upscale 합성하도록 했다.
- cloud 합성 shader가 cloud slab 진입 깊이를 `gl_FragDepth`로 출력하고 scene depth test를 사용하도록 해, 구름 위나 안에서 아래 지형이 구름을 무조건 덮어버리는 문제를 줄였다.
- 구름 volume wind offset을 게임 내 하루 동안 X축 1타일만큼 이동하도록 바꿔, 하루 동안 구름 패턴이 100% 흐르도록 했다.
- `cloudCoverage`의 밀도 배율 적용을 제거하고, threshold를 `1.0 - cloudCoverage`로 단순 반전하도록 바꿨다.
- 원형 줄무늬를 줄이면서 시간에 따른 자글거림을 피하기 위해 raymarch jitter를 `screenNoise(gl_FragCoord.xy)` 기반 고정 jitter로 바꿨다.

## 결정 사항
- 구름 높이 범위는 기존 `Y=520..640`을 유지한다.
- SunshineClouds2 전체 compute/temporal 구조를 한 번에 옮기지 않고, 먼저 기존 renderer 구조 안에서 3D volume density model과 1/4 픽셀 low-res cloud pass를 붙이는 1차 포팅으로 진행한다.
- 3D cloud texture는 우선 mipmap 없이 1레벨로 생성한다. 형태 확인 후 성능과 aliasing 문제가 있으면 3D mip 또는 temporal accumulation을 검토한다.
- low-res cloud pass는 가로/세로 1/2, 총 픽셀 수 1/4 기준으로 사용한다. 가로/세로 1/4는 품질 손실이 커질 수 있어 보류한다.
- 현재 depth 처리는 scene depth texture를 직접 읽지 않고, 합성 pass에서 cloud slab entry depth를 출력해 hardware depth test에 맡긴다.
- 구름 흐름은 우선 X축 단일 방향으로 둔다. 하루 뒤 같은 texture tile 위치로 돌아오므로 반복이 안정적이다.
- `cloudCoverage`는 구름 면적 조절값으로만 사용하고, 구름 불투명도는 raymarch 누적 밀도와 통과 거리가 결정하게 둔다.
- raymarch jitter는 시간값을 섞지 않고 화면 픽셀 기준으로 고정해, 움직이지 않을 때 매 프레임 샘플 시작점이 바뀌지 않도록 한다.

## 이슈
- 빌드는 사용자가 직접 수행한다.
- 현재 단계는 SunshineClouds2의 depth prepass, temporal accumulation, lightmarch를 아직 포함하지 않는다.
- cloud entry depth 기반 합성은 terrain 앞뒤 관계의 큰 문제를 해결하지만, raymarch 자체를 scene depth에서 조기 종료하는 완전한 depth-aware marching은 아니다.
