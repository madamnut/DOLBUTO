## 결정 사항
- `craft`의 새 형식은 특정 주 대상 없이 `inputs[]`를 동등한 입력으로 취급한다.
- 입력 alias는 `as`를 사용한다.
- 입력 값 비교는 `constraints`에서 `==`, `in` 연산자로 표현한다.
- head+binding+handle의 세부 결과 계산은 JSON 표현식이 아니라 `derive.type = head_binding_handle` 내부 로직으로 처리한다.
- 손 아이템 렌더는 기존 `itemId`를 정적 정의 조회와 빈 슬롯 판정에 유지하되, 동적 렌더 상태는 `ItemStack`으로 전달한다.
- 동적 합성 도구는 텍스처 layer뿐 아니라 알파 실루엣 기반 mesh도 합성 텍스처 이름으로 조회한다.
- radial 제작 후보 아이콘은 출력 스택 override가 있으면 정적 아이템 슬롯 텍스처보다 동적 슬롯 텍스처를 우선한다.
