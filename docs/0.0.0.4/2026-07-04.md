# 2026-07-04 산소 후처리 조정

## 작업 기록
- 산소 부족 터널비전의 가장자리 영역을 완전 검정으로 덮도록 조정했다.
- 터널비전 경계는 `smoothstep` 구간을 유지해 흐릿하게 보이도록 했다.
- 산소 효과값이 `0.98`을 넘으면 `1.0`으로 스냅해 산소 고갈 상태에서 장면 색이 완전 흑백이 되도록 했다.
- 물속 화면 tint는 산소 부족 효과가 강해질수록 alpha가 줄어들고, 산소 고갈 상태에서는 완전히 사라지도록 했다.

# 2026-07-04 산소 구현 기록

## 작업 기록
- 플레이어 산소 스탯과 HUD 산소 게이지를 추가했다.
- 산소는 Survival 모드에서 1인칭 눈 위치가 물속이면 15초 동안 100에서 0까지 감소하고, 물 밖에서는 30초 동안 0에서 100까지 회복하도록 했다.
- Sandbox 모드에서는 산소를 항상 최대값으로 유지하고 익사 피해를 적용하지 않도록 했다.
- 산소가 0인 채 물속에 있으면 1초마다 HP 10 피해를 주고, 기존 플레이어 피해 사운드/화면 흔들림/3인칭 red flash 피드백을 재사용하도록 했다.
- 산소가 절반 이하일 때 scene composite 단계에서 화면 흑백화와 청흑색 비네트 효과가 점점 강해지도록 했다.
- 산소 부족 비네트는 고정 범위 어둡기 방식이 아니라, 산소가 줄수록 가장자리에서 중앙으로 좁아지는 검은 터널비전 방식으로 조정했다.
- `player.dat` 저장 포맷에 oxygen/maxOxygen `uint16` 값을 추가했다.

## 결정 사항
- 산소 수중 판정은 플레이어 AABB가 아니라 1인칭 카메라/눈 위치 기준으로 처리한다.
- 산소 부족 후처리는 UI가 아니라 게임 장면 composite에만 적용한다.

# 2026-07-04

## 작업 기록
- `plant` 아이템의 `components.placeable`을 제거해 손에 든 plant로 plant 블록을 설치하지 못하도록 했다.
- 현재 설치 아이템 기준 문서에서 `plant` 항목을 제거했다.
- Survival + Ground 모드에서만 누적되는 낙하 피해를 추가했다.
- 낙하 피해 공식은 `ceil(fallDistance - 2.5) * 6`으로 두고, 사망 처리가 없으므로 HP는 최소 `1`까지만 감소하도록 했다.
- Sandbox 모드, fly 이동, 물 접촉 상태에서는 낙하 거리 기록을 끊도록 했다.
- 낙하 피해를 받으면 `PlayerTookDamage.wav`를 2D SFX로 재생하고, HP HUD 갱신과 화면 흔들림, 3인칭 플레이어 모델 red flash를 적용하도록 했다.
- 1인칭 손과 든 아이템에는 피해 red flash를 적용하지 않도록 했다.
- 낙하 피해 red flash를 기존 색과 약하게 섞는 방식이 아니라 순수 빨강으로 덮는 방식으로 조정하고, 화면 흔들림 지속시간과 강도를 키웠다.

## 결정 사항
- `plant` 아이템은 연료와 가공 재료로만 사용하고, 직접 블록 설치 아이템으로 취급하지 않는다.
- 낙하 피해는 Minecraft처럼 거리 기반으로 처리하되, 현재 HP 최대값 `100`에 맞춰 Minecraft보다 더 엄격한 피해량으로 시작한다.
- Sandbox/Fly 상태에서 발생한 낙하 기록은 Survival 전환 이후로 이어받지 않는다.
- 죽음 처리는 아직 구현하지 않는다.
