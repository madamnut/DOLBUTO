- 산소 부족 터널비전의 가장자리 영역을 완전 검정으로 덮도록 조정했다.

# 2026-07-04 산소 구현 기록

## 작업 기록
- 플레이어 산소 스탯과 HUD 산소 게이지를 추가했다.
- 산소는 Survival 모드에서 1인칭 눈 위치가 물속이면 15초 동안 100에서 0까지 감소하고, 물 밖에서는 30초 동안 0에서 100까지 회복하도록 했다.
- Sandbox 모드에서는 산소를 항상 최대값으로 유지하고 익사 피해를 적용하지 않도록 했다.
- 산소가 0인 채 물속에 있으면 1초마다 HP 10 피해를 주고, 기존 플레이어 피해 사운드/화면 흔들림/3인칭 red flash 피드백을 재사용하도록 했다.
- 산소가 절반 이하일 때 scene composite 단계에서 화면 흑백화와 청흑색 비네트 효과가 점점 강해지도록 했다.
- 산소 부족 비네트는 고정 범위 어둡기 방식이 아니라, 산소가 줄수록 가장자리에서 중앙으로 좁아지는 검은 터널비전 방식으로 조정했다.
- `player.dat` 저장 포맷에 oxygen/maxOxygen `uint16` 값을 추가했다.

## 결정 사항
- 산소 수중 판정은 플레이어 AABB가 아니라 1인칭 카메라/눈 위치 기준으로 처리한다.
- 산소 부족 후처리는 UI가 아니라 게임 장면 composite에만 적용한다.

- `plant` 아이템의 `components.placeable`을 제거해 손에 든 plant로 plant 블록을 설치하지 못하도록 했다.

- Sandbox/Fly 상태에서 발생한 낙하 기록은 Survival 전환 이후로 이어받지 않는다.
- 죽음 처리는 아직 구현하지 않는다.

# 2026-07-04 Complementary식 그림자 구조 전환

## 작업 기록
- 기존 3-cascade shadow map 구조를 단일 shadow space 구조로 줄였다.
- shadow map은 frame-in-flight별 depth texture array의 0번 layer만 사용하고, shadow pass도 한 번만 렌더링하도록 정리했다.
- shadow view는 하늘과 같은 `sunDirection`을 기준으로 하고, 빛 진행 방향은 `-sunDirection`으로 통일했다.
- terrain/player shadow caster vertex shader와 terrain/godray receiver sampling에 같은 shadow distortion 함수를 적용했다.
- terrain 조명 shader의 cascade 선택과 previous shadow blend를 제거하고 단일 shadow map layer 0의 Poisson PCF만 사용하도록 정리했다.
- godray shadow sampling도 같은 단일 shadow map layer 0과 distortion 기준으로 맞췄다.
- `docs/design/rendering.md`의 그림자 설명을 현재 구현 기준으로 갱신했다.

## 결정 사항
- Complementary식 시각 개선을 우선하기 위해 기존 CSM 구조를 유지하지 않고 단일 shadow space + distortion 구조로 갈아탄다.
- colored shadow, translucent shadow, water tint shadow는 이번 단계에서 제외한다.

## 이슈

# 2026-07-04 갓레이 그림자맵 기반 전환

## 작업 기록
- 기존 presentation pass radial blur 방식 갓레이를 제거하고, scene depth와 CSM shadow map을 샘플링하는 fullscreen volumetric light shaft 패스로 교체했다.
- 월드 scene pass 직후 scene color target에 갓레이를 additive로 누적하고, 1인칭 viewmodel은 color load/depth clear 전용 scene load pass에서 다시 그리도록 렌더 순서를 분리했다.
- 갓레이 전용 descriptor set layout, descriptor set, framebuffer, pipeline render pass 연결을 추가했다.
- `god_rays.frag`를 카메라 raymarch + shadow visibility 누적 방식으로 교체했다.
- 갓레이 ray 재구성 기준을 sky shader 기준이 아니라 terrain pass가 scene depth를 만들 때 쓰는 view/projection basis 기준으로 정리했다.
- normalized ray 거리 누적 방식 대신 각 샘플의 view-space Z에서 world position을 복원하는 방식으로 갓레이 raymarch를 다시 정리했다.
- `docs/design/rendering.md`의 갓레이 설명을 현재 구현 기준으로 갱신했다.

## 결정 사항
- 갓레이는 최종 swapchain presentation pass가 아니라 scene color target 단계에서 처리한다.
- viewmodel depth clear가 월드 depth를 지우지 않도록 viewmodel 렌더링을 갓레이 이후 별도 scene load pass로 분리한다.
- 태양이 화면 내부에 있어야만 작동하는 제한은 제거하고, 카메라가 태양 방향을 향하는 정도로 갓레이 강도를 제한한다.

## 이슈
- 빌드는 사용자가 직접 수행한다.
