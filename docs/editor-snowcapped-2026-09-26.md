## 범위와 출처

- 원본 https://github.com/jacobsjo/snowcapped 의 index.html/public/style.css와 Wiki/Snowcapped-UI를 확인. MIT 팔레트와 메뉴/왼쪽 목록/중앙 격자·곡선/오른쪽 접이식 지도 구조를 참고해 기존 프론트엔드를 적응했다. 전체 upstream TypeScript나 Minecraft 계산기/기본 데이터는 가져오지 않았다. assets/licenses/Snowcapped.txt에 출처와 원문 라이선스 유지.
- 목표는 현 생성 기능의 원본식 편집 체계. 바이옴 Slices/Layouts·바이옴 페인트·datapack 내보내기/바이옴배치는 미구현이며 이번 범위에 추가하지 않는다. 원본 전체와 기능·픽셀 동일을 주장하지 않는다.
- 기존 C++ 생성기/schema8/시드/4D Simplex·3D Perlin/개별 워핑/순환 좌표/저장 규칙은 유지. 사용자 settings/worldgen 파일은 변경하지 않는다.

## 화면과 조작

- assets/editor/index.html/style.css/app.js/map-view.js 네 파일 유지. 왼쪽 지형 offset/factor/jaggedness/생성 설정, 모든 노이즈와 워핑 목록, 온도/강수 목록. 기본은 offset 격자/지도. 기존 3D설정·높이곡선·구형조합은 생성설정에 보존.
- 가운데 스플라인은 별도 modal이 아닌 인라인 격자/곡선 보기. 칸 클릭으로 곡선 진입, 격자 버튼으로 복귀. 선택 C/E 드롭다운과 단계별 breadcrumb. 같은 실행 중 칸 값/하위 트리 복사·붙여넣기. 마지막 지정 칸을 null로 지우는 붙여넣기는 거부한다.
- 상단 저장/파일/되돌리기와 원본계열 밝은/어두운 팔레트, 지도접기/지도확대. CSS 3열은 좁은 화면에서 지도를 아래로 옮기고 작은 폭에서는 목록도 위쪽으로 이동. 외부 폰트/CDN/분석스크립트 추가없음.
- 지도 자동갱신 기본ON, 끌수있음. 숫자편집은기존180ms디바운스/최신요청스케줄러,곡선드래그는포인터놓을때지도갱신. 비교/PNG/원좌표범위/옥타브/워핑전/확정저장경로유지. undo도자동갱신을따름.
- 지도클릭 probe에서 현재작업의최신지도만 가까운C/E제어칸열기 제공. 가장가까운격자점이며해당위치가오직그칸으로결정된다는뜻이아님을설명한다. 비교기준·오래된지도에서는비활성화.

## 곡선 계산/직접 편집

- 기존 /api/curve 최종 Weirdness 단면 유지. 옵션 node_path/cell/preview_weirdness 추가. 경로최대8/칸범위/노드범위/finite 검사. 지역격자나생성기를변경하지않고복사한현재단계의입력축을직접표시한다. PV단계도PV자체가가로축이다.
- 하위노드는 UI에서명시한 W(-1..1,초기0)에고정해각제어점값을평가한다. 복사노드의하위값을그결과상수로대체하고TerrainSpline::evaluate로257표본생성. 최종전체W단면과자체축편집그래프를따로표시하여중첩결과와편집단면을혼동하지않는다. JS에생성수식복제없음.
- 제어점드래그는입력좌표(-2..2/인접점.001간격)와상수출력(-64..64)을편집. 하위곡선값은드래그로상수화하지않으며X만수정. Shift드래그는접선(-64..64),숫자입력도보존. 현재단계그래프는60ms디바운스갱신,드래그중축범위고정,완료시최종곡선도재계산. 드래그1회 undo1항목.
- 그래프별요청번호로동시에표시하는최종단면/현재단계곡선이서로응답을취소하지않도록변경했다. 삭제된canvas로돌아온응답은버린다.
