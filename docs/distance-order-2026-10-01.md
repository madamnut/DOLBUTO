# 카메라 XZ 거리순 청크 렌더링 (2026-10-01)

사용자가 모든 청크의 거리순 렌더링을 즉시 적용하도록 요청하고, 정렬 기준은 카메라/청크 XZ만 사용하도록 정정했다. 해당 동작을 적용했다. 전체 GPU 개선은 거리별로 다르며 일괄적인 성능 향상으로 판단하지 않는다. 기존 블룸16샘플/descriptor 재사용은 유지한다.

## 구현

- 매 렌더 프레임 실제 카메라 XZ와 청크 중심 XZ 사이의 거리 제곱을 계산한다. Y는 사용하지 않는다. world_delta로 순환 월드의 최단 XZ 차이를 사용하며 LOD는 실제 타일 폭의 중심을 쓴다.
- 일반 지형·디버그·그림자·얼음·물 반사 마스크·물 깊이는 가까운 순서, 물 색 합성은 먼 순서다. 각 패스의 근거리/LOD를 병합하므로 기존처럼 한 종류를 통째로 먼저 그리지 않는다. 그림자도 사용자 지정 카메라 기준을 따른다.
- 같은 거리에는 좌표 tie-break를 사용한다. 동일 청크의 면/LOD upload part 내부 순서는 유지한다. 플레이어는 청크가 아니며 별도로 그린다. 서로 다른 효과의 렌더 패스 실행 순서는 유지한다.
- WorldView가 가시 목록을 정렬하고 LodRenderer가 캐시된 타일 목록의 거리를 갱신한다. 다음 가시 타일의 거리까지 근거리 구간을 제출하고 마지막 남은 구간을 비운다. 전환 때 pipeline/descriptor만 복원하며 깊이 clear/snapshot/렌더 패스를 반복하지 않는다.
- `--profile-near-detail`에 근거리와 LOD를 함께 검사하는 단조 거리 진단을 추가했다. 역전은 오류로 종료하고 성공 횟수는 `DRAW ORDER`에 기록한다. 일반 성능 계측에서는 꺼둔다.

## 비교 조건

Windows/i7-14700F/RTX5060, Release, Vulkan headless 1280×900. 기존 평평한 돌 지형/seed1337, LOD64, 그림자 품질2·거리192, 블룸12/TAA ON 등 동일 설정. 카메라 높이193.6/yaw−90/pitch−22/12시/원점0,0. near/LOD 준비 완료 후240프레임 예열, 실행당640steady. 거리12/24/32를 각3쌍, 총18회/11,520steady 측정했고 두 번째 반복은 순서를 뒤집었다. 동시에 다른 게임 계측 프로세스를 실행하지 않았다.

## 검증

기본 지상·순환 경계·상공·근거리 디버그 전후8회는 validation ON/TAA OFF/블룸40, 각64steady. 모든 실행 exit0/Vulkan 오류0/기존 shader interface warnings10, 지형 draw/triangles/LOD tiles 일치. 정상 성능18회는 오류0/warnings0,CPU/GPU frame 매칭·LOD 완료·steady descriptor 쓰기0 확인.

- 지상·순환 경계·근거리 디버그 캡처는 픽셀 완전 동일.
- 상공 캡처는1,152,000픽셀 중218픽셀(0.0189236%) 차이, 채널 차이 최대17/255, 평균0.00020515/255. 초기/최종 빌드에서 동일하게 재현됐다. 전체 이미지에서 큰 형상 변화는 보이지 않았으나 픽셀 동일성을 주장하지 않는다.
- 지상 raw 그림자 깊이2종/색2종과 extent는 파일 단위 동일.
- 최종 지상/경계/상공에서 각각2,046,684/1,959,018/2,137,443회 거리순 검사 통과. 이는 로딩/예열/steady를 합한 진단 횟수이며 draw 수 감소를 뜻하지 않는다.

추가 전후4회도 exit0/Vulkan 오류0/기존 warnings10. LOD OFF 반대 방향 시점(64steady)은 픽셀 동일/후보761,425회 순서 검사 통과. LOD ON 디버그 상공(4,096steady)은 완료 시666타일/LOD pending0/마지막500프레임 삼각형 수 안정 및 전후 geometry 일치. 디버그 캡처는25픽셀(0.0021701%) 차이/채널 최대240/255/평균0.00264149/255로 픽셀 동일하지 않다. 최초 추가 디버그의60,000샘플 시도는 과도한 검증 시간 때문에192.76초에 자체 프로세스를 중단했다. 해당 exit−1 로그/메타데이터는 oversized-debug-attempt에 제외 기록으로 보존하고, 최종4,096샘플을 별도로 완료했다. 현재 임시 돌 평지에는 물·얼음이 없어 해당 색/반사/깊이 경로는 소스와 descriptor 복원 경로 검토에 한정한다. 수중·유체 편집·실제 카메라 입력 이동·리사이즈는 실행 검증하지 않았다. 자동 테스트/CTest/CU/합성 입력은 추가하거나 실행하지 않았다.
