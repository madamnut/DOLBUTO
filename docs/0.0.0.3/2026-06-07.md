# 2026-06-07

- 드랍 `extruded_sprite` 아이템의 물리 AABB와 렌더/상호작용 bounds를 분리했다. 물리 충돌은 `0.2 x 0.05 x 0.2`, 렌더링/플레이어 접촉 획득/레이캐스트/작업영역 감지는 `0.5 x 0.05 x 0.5`를 사용한다.

## 작업 기록
- 지형/오브젝트의 시간대별 `skyBrightness`는 유지하고, sky shader의 밤하늘 RGB ramp만 낮춰 완전히 어두운 시간대의 하늘을 더 어둡게 보이도록 조정했다.
- 손 아이템 부착 노드가 포함된 캐릭터 GLB를 `Character.glb`로 통합하고, 기존 `Characterwithanim.glb`/`Characterhandattatch.glb` 파일을 제거했다.
- 플레이어 모델 로드 경로를 `assets/textures/character/Character.glb` 단일 파일 기준으로 단순화했다.
- 3인칭 플레이어 렌더링에서 선택 핫바 아이템은 `Attach_R`, 왼손 슬롯 아이템은 `Attach_L` node에 붙여 보이도록 했다.
- item instance buffer에 basis 축을 추가해 3인칭 손 아이템이 플레이어 손 node의 최종 transform을 따라가도록 했다.
- 3인칭 손 아이템이 위아래로 뒤집혀 보이지 않도록 부착 렌더에서 Y/Z basis를 뒤집는 로컬 180도 보정을 적용했다.
- 꺼진 `torch`도 `burnTicks` 슬롯 게이지를 사용해, 일부 탄 뒤 꺼진 횃불의 남은 연소 시간이 슬롯에 표시되도록 했다.
- scene pass에 bloom source target을 추가하고, 첫 bloom downsample 입력을 scene color가 아니라 bloom source로 변경했다.
- 태양/달 스프라이트는 `sprite_scene.frag`에서 texture alpha가 있는 픽셀을 bloom source에 기록하도록 했다.
- 불 terrain fragment는 fire texture alpha가 있는 픽셀만 bloom source에 fire 색을 기록하도록 했다.
- 구름, blend 지형, 유체는 bloom source에도 검정 alpha를 기록해 뒤쪽 태양/달 bloom을 같은 비율로 가리도록 했다.
- 3인칭 카메라가 피벗에서 목표 위치까지 지형 충돌을 샘플링해 첫 충돌 직전 거리로 보정되도록 했다.
- 0.0.0.3 마감용 `SUMMARY.md`를 작성했다.
- `assets/data`, `config`, `assets/ui`의 JSON 파싱, 아이템/블록/유체 ID 중복, 아이템/블록/레시피/셰이더 참조 정합성을 확인했다.
- `git diff --check`로 공백 오류를 확인했다. 실제 오류는 없고 Git의 LF/CRLF 변환 경고만 출력되었다.

## 결정 사항
- 밤하늘 밝기 조정은 지형 조명 밸런스를 바꾸지 않기 위해 `GameClient::skyBrightnessForTicks`가 아니라 `shaders/sky.frag`의 night ramp에서 처리한다.
- 플레이어 모델은 앞으로 `Character.glb` 하나만 기준으로 관리하고, 3인칭 손 아이템 부착 기준은 GLB 내부의 `Attach_L`, `Attach_R` node를 사용한다.
- 드랍 아이템, 3인칭 손 아이템, 1인칭 viewmodel 아이템은 같은 `DroppedItemRenderPath`를 재사용하되, frame instance buffer 안에서 서로 다른 예약 영역을 사용한다.
- 블룸 기준은 scene color 밝기 threshold가 아니라 bloom source target에 기록된 alpha 마스크 기반 픽셀로 둔다.
- 태양 주변 대기광은 `sky.frag`의 `solarGlare`로 유지하고, 태양/달 스프라이트 자체 번짐은 bloom source 기반 포스트 블룸으로 처리한다.
- 3인칭 카메라 충돌은 별도 물리 엔티티가 아니라 렌더 프레임의 카메라 위치 보정으로 처리한다.
- 0.0.0.3 마감 검증은 기존 세이브 호환보다 새 월드 기준의 현재 구조 검증을 우선한다.
