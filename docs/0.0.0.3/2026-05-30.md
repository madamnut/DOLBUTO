# 2026-05-30

## 작업 기록
- 블룸 포스트 프로세스를 추가했다.
- scene color target은 지원되는 경우 `VK_FORMAT_R16G16B16A16_SFLOAT` HDR 포맷을 사용하고, 미지원 GPU에서는 swapchain 포맷으로 되돌린다.
- 초기 블룸 구현은 밝은 픽셀을 1/4 해상도 target에 추출하고, 기존 카와세 블러 패스를 재사용해 두 번 번지는 방식이었다.
- 블룸을 단일 카와세 blur 방식에서 dual-filter bloom 방식으로 교체했다.
- `bloom_downsample.frag`와 `bloom_upsample.frag`를 추가하고, 1/4, 1/8, 1/16, 1/32 해상도 target을 순차 downsample/upsample한다.
- 달 스프라이트에 따뜻한 흰노란 tint를 곱해 블룸에 은은하게 잡히도록 했다.
- Sandbox 모드 블록 파괴를 즉시 파괴로 바꾸고, 좌클릭 유지 반복 파괴만 10틱 간격으로 제한했다.
- 최종 presentation pass에 additive sprite pipeline을 추가해 scene color 위에 블룸 텍스처를 더한다.
- `config/render.json`에 `bloom.enabled`, `threshold`, `intensity`, `radius`를 추가했다.
- `fire` terrain fragment는 HDR target에서 threshold를 넘도록 색을 2배로 올린다.
- `fire` 렌더링 배치를 중앙 X자 2장과 바닥 네 변에서 중심으로 기울어진 쿼드 4장으로 수정했다.
- `fire/fire_00`부터 `fire/fire_13`까지 14프레임을 block texture array에 연속 등록하고, terrain shader에서 시간 기반으로 현재 프레임을 선택하도록 했다.
- 불 바닥 네 변에 90도 수직 쿼드 4장을 추가하고, 애니메이션 속도를 초당 12프레임으로 조정했다.
- 불 수직 90도 쿼드 4장을 바닥 변에서 안쪽으로 0.1블록 당겨 배치했다.
- `bow_drill` 아이템을 추가하고 `ignite` 우클릭 액션을 부여했다.
- `interactions.json`에 블록 대상 레시피(`targetBlock`)와 블록 설치 후보를 지원하도록 데이터/실행 경로를 확장했다.
- `ignite` 후보 실행 시 대상 블록 바로 윗칸에 `fire` 블록을 설치하도록 했다.
- `primal_workbench`처럼 블록 자체 액션이 있는 대상은 기본 우클릭에서 블록 액션을 우선하고, `Shift + 우클릭`일 때 손에 든 아이템의 블록 대상 액션을 우선하도록 했다.
- 작업대 레시피로 `wooden_stick` 2개와 `plant_twine` 1개를 `craft`해 `bow_drill`을 만들 수 있게 했다.
- 물에 닿아 있거나 물 밖 기어오르기 중이면 View Bobbing 카메라 흔들림을 적용하지 않도록 했다.
- `coal_ore`, `copper_ore`, `iron_ore`, `tin_ore`, `zinc_ore`, `silver_ore`, `gold_ore` 블록 데이터를 추가했다.
- 블록 텍스처 정의가 문자열뿐 아니라 `{ "base": "...", "mask": "..." }` 객체도 받을 수 있게 하고, 로드 시점에 base 텍스처 위에 mask 텍스처를 합성해 `assets/textures/block/generated/` 아래에 생성하도록 했다.
- `ResolveFeatures` 단계에 `coal_ore` 시험 생성용 광물 blob feature를 추가했다.
- `coal_ore`는 3x3 source chunk 좌표에서 결정적 난수로 청크당 60회 시도하며, Y `200~511` 범위에서 size 25 blob을 만들고 `rock`만 치환한다.
- 광물 blob 설정을 `config/world.json`의 `features.ores` 배열로 옮기고, `coal_ore`, `copper_ore`, `tin_ore`, `gold_ore`, `iron_ore`를 등록했다.
- 현재 기본 설정에서는 `coal_ore`만 `enabled: true`이고 나머지 광물은 꺼둔다.
- `dirt` 블록 파괴 드랍을 `dirt_pile` 4개 확정으로 변경했다.
- `grass` 블록 파괴 드랍을 `dirt_pile` 4개 확정, `grass_scrap` 2~4개 확정으로 변경하고 `seed` 확률 드랍은 유지했다.
- 광물 원재료 아이템을 추가하고 금속 광물 스프라이트 파일명을 `raw_*` 형식으로 정리했다. `rock`은 `rock_chunk` 4개를 확정 드랍하고, 광물 블록은 `rock_chunk` 4개와 광물별 원재료 1개를 확정 드랍하도록 했다.

## 결정 사항
- 블룸은 우선 불 같은 강한 발광 표현을 위한 화면 공간 post-process로 둔다.
- 별도 가우시안 블러 대신 기존 물속 화면 흐림에서 쓰던 카와세 블러를 재사용한다.
- 실제 화면 확인과 튜닝은 사용자가 직접 빌드 후 진행한다.
- 불 애니메이션은 개별 블록별 오프셋 없이 모든 `fire` 블록이 같은 프레임을 공유하는 단순 동기화 방식으로 처리한다.
- 지형 메쉬는 `fire/fire_00` layer만 저장하고, 프레임별 texture layer 치환은 shader에서 처리해 불 애니메이션 때문에 메쉬를 다시 만들지 않는다.
- 불 피우기 결과는 현재 아이템 드랍이 아니라 블록 결과 후보로 처리하며, 배치는 `above_target`만 지원한다.
- 광물 텍스처는 개별 완성본을 수동으로 두지 않고, `rock` 기반 텍스처와 `assets/textures/block/mask/`의 광물 마스크를 로드 시 합성하는 방식으로 둔다.
- 일반 광물 생성은 전체 3D 노이즈 필드 스캔이 아니라, feature 배치 시도 위치를 뽑고 해당 위치 주변의 작은 blob만 검사하는 방식으로 둔다.
- 광물별 높이, 시도 횟수, 크기는 월드 설정에서 조절한다.
