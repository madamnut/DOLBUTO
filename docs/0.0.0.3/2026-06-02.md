## 결정 사항
- 플레이어가 직접 선택해 즉시 실행하는 레시피는 `interactions`, 환경/장치 상태로 시간 경과 처리되는 레시피는 `processings`로 분리한다.
- 도기 굽기는 `firing` processing으로 정의하고, 6방향이 밀폐된 fire가 `coal` 또는 `charcoal`을 연료로 소비했을 때만 진행한다.
- 신규 점토/가공 재료 아이템은 우선 모두 `extruded_sprite`, `stackSize = 99`, 빈 액션 목록으로 등록한다. 현재 제작/처리 연결은 `clay_pile`, `refractory_clay_pile`, 벽돌, 점토 냄비 계열까지만 적용하고 크루시블은 에셋과 블록 구현이 준비된 뒤 연결한다.
- 점토 디스크는 청크의 `16 x 16 x 512` 전체에서 XYZ를 무작위로 고르지 않고, source chunk 내부 X/Z만 무작위로 고른 뒤 수중 바닥 Y를 사용한다.
- 1차 설정은 청크당 `20%` 확률로 1회 시도, 반지름 `4~6`, `halfHeight = 1`로 둔다.
- 왼손 슬롯은 인벤토리 화면의 50칸 패널에는 표시하지 않고, HUD 전용 슬롯으로 표시한다.
- 0레벨 연료는 구분하지 않고, 실제 연료 온도 단계는 1부터 시작한다.
