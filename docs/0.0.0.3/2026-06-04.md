## 작업 기록
- `bark_strip`을 `pyrolysis`로 처리하면 `tar` 1개가 나오도록 processing 레시피를 추가했다.
- 드랍 아이템 스택 병합 조건에 내구도 비교를 추가해, 같은 아이템이라도 내구도나 processing 진행 상태가 다르면 병합하지 않도록 했다.
- `dirt_half_slab` 아이템과 블록을 추가했다.
- `dirt_half_slab`은 `dirt_pile` 1개를 `handcraft` 또는 작업대 `craft`로 만들어 설치할 수 있으며, 기존 `half_slab` 렌더 타입과 `attach_grid` 배치 상태를 사용한다.
- `block_model` 아이템 렌더링의 `modelShape`에 `half_slab`을 추가했다.
- 관련 설계 문서의 아이템 데이터, 블록 데이터, 상호작용 레시피, processing 레시피 내용을 현재 구현 기준으로 갱신했다.

## 결정 사항
- `dirt_half_slab`은 새 렌더 타입을 만들지 않고 기존 `half_slab` 블록 렌더링과 충돌/배치 로직을 재사용한다.
- `modelShape = "half_slab"`은 `quarter_log`와 같은 크기지만 수직 단면 텍스처를 쓰지 않는 일반 조각 표시 모델로 분리한다.
- 시간 기반 processing 중인 드랍 스택은 진행 tick, 처리 종류, 내구도가 모두 같을 때만 병합한다.
