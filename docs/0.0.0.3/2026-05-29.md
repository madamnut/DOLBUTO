## 작업 기록
- 카메라가 수면보다 충분히 아래에 있을 때 물속 화면 blur가 전체 화면에 적용되도록 수정했다.
- 물속 화면 흐림을 fullscreen 9-tap 방식에서 quarter resolution Kawase blur 2-pass 방식으로 변경했다.
- 물속 화면 흐림 설정명을 `spread`, `intensity`, `tint`로 바꿔 현재 Kawase blur 방식에 맞게 정리했다.
- 물속 blur pass 이후 swapchain presentation viewport/scissor를 전체 화면 크기로 복구하도록 수정했다.
- 플레이어 AABB가 물에 닿으면 수영 이동을 적용하고, 물속 `Space` 상승/`Shift` 하강과 물 밖 1블록 올라가기 보정을 추가했다.
- 물속에서 입력 없이 가만히 있으면 천천히 하강하고, `Shift`를 누르면 더 빠르게 하강하도록 수영 Y축 속도를 분리했다.
- 엎드리기 기어오르기를 target 보간 방식에서 수평 충돌을 해소하는 step-up 방식으로 변경했다.
- 엎드리기 step-up 기어오르기의 tick당 상승량을 제한해 한 번에 튀어오르지 않도록 조정했다.
- 엎드리기 기어오르기를 1칸 벽 판정 후 최대 1블록 높이까지 천천히 상승하는 상태 기반 처리로 정리했다.
- 물 밖 기어오르기도 엎드리기와 같은 1칸 벽 판정 및 상태 기반 상승 처리로 맞췄다.
- 물 밖 기어오르기 중 현재 높이에서 정면 충돌이 해소되면 수평 이동만 적용하고 추가 상승을 멈추도록 수정했다.
- 기본 손 `handcraft` 액션과 식물 끈 계열 아이템/레시피를 추가했다.
- 아이템 상호작용 레시피에 1회당 대상 소비량 `targetCount`를 추가하고, 우클릭 해제 시 `Shift`가 눌린 경우에만 반복 제작하도록 변경했다.
- `handcraft`를 빈손 전용이 아니라 어떤 아이템을 들고 있어도 유지되는 기본 손 액션으로 변경했다.
- 대상 스택 개수가 부족해 제작할 수 없는 원형 UI 후보는 해당 후보의 바깥 링 구간을 빨간색으로 표시하도록 변경했다.
- 원형 상호작용 UI가 처음 열릴 때 단일 액션도 자동 선택하지 않고 중앙 `Cancel` 상태로 시작하도록 변경했다.
- `long_plant_twine`을 `cut`하면 `plant_twine` 2개가 나오도록 추가해 식물 끈 길이 계열을 양방향 가공으로 맞췄다.

## 결정 사항
- 물속 효과 강도는 깊이에 따라 바꾸지 않고, 수면 근처 분할 표시와 완전 잠수 전체 화면 표시만 구분한다.
- 물속 blur는 scene color를 작은 render target에 두 번 처리한 뒤 최종 presentation에서 물속 영역에만 섞는다.
- `spread`는 퍼짐 정도, `intensity`는 원본과 blur 결과의 혼합 비율, `tint`는 물색 혼합 강도로 사용한다.
- Sandbox fly 상태에서는 물속에서도 공기 중 fly와 같은 이동 규칙을 사용한다.
- 식물 섬유/끈 제작은 기본 손 `handcraft`로 결합하고, 끈을 짧게 나누는 작업은 `cut`으로 처리한다.
