# 2026-05-28

## 작업 기록
- 물속 화면 흐림 효과를 깊이 기반 오버레이 방식에서 단순한 scene composite shader 방식으로 변경했다.
- `fluid.water.screenBlur` 설정을 `enabled`, `radiusPixels`, `amount`, `tintAlpha`로 정리했다.
- 수면선 자체에는 별도 효과를 주지 않고, 화면에서 물속 영역만 나눠 고정 강도의 blur/tint를 적용하도록 했다.

## 결정 사항
- 물속 표현은 당분간 픽셀별 거리 계산이나 깊이별 강도 변화 없이 화면 공간 blur만 사용한다.
- blur는 swapchain presentation 단계에서 scene color를 한 번 합성하는 전용 pipeline으로 처리한다.

## 이슈
- 빌드와 실제 화면 확인은 사용자가 직접 수행한다.
