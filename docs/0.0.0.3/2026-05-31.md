# 2026-05-31

## 작업 기록
- `assets/textures/particle/smoke/smoke_0.png`부터 `smoke_7.png`까지의 연기 파티클 텍스처를 smoke particle texture array로 로드하도록 했다.
- `ParticleRenderPath`에 불 연기 파티클과 활성 fire emitter 목록을 추가했다.
- fire emitter는 블록 설치/제거와 청크 로드/언로드 시점에 갱신하고, 매 프레임 전체 월드를 스캔하지 않도록 했다.
- 연기 파티클은 위로 천천히 상승하고 X/Z 방향으로 약하게 흔들리며, 생성 시점 크기를 유지하도록 했다.
- 연기 파티클은 solid terrain cell과 충돌하면 해당 축 이동을 막고 튕기지 않도록 했다.
- 불 연기 파티클 크기를 `0.8~1.0`블록으로 키우고, 충돌 검사는 중심점 기준으로 단순화했다.
- 연기 파티클은 수명 비율에 따라 `smoke_0`부터 `smoke_7`까지 한 번 재생하고, alpha fade-in/fade-out을 적용하도록 했다.
- particle pipeline에 alpha blending을 켜고, 파티클 vertex의 `alphaBlend` 값을 shader로 전달하도록 했다.
- `charcoal` 아이템을 `assets/data/items.json`에 추가했다.
- 아이템 데이터에 `burnTimeTicks`를 추가하고 초반 식물/나무/석탄 계열 연료 시간을 설정했다.
- `fire` 블록의 남은 연소 시간을 block entity로 저장/로드하고, 연료 드랍 아이템을 소비해 연장되도록 했다.
- 불은 연소 시간이 끝났을 때 같은 셀 영역의 연료 중 가장 짧은 연소 시간 아이템을 1개 소비하고, 연료가 없으면 꺼지도록 했다.

## 결정 사항
- 불 연기는 월드 데이터가 아니라 렌더만 하는 런타임 파티클로 둔다.
- 연기 파티클은 별도 particle texture array를 사용하되, 기존 particle pipeline과 billboard 렌더 경로를 재사용한다.
- fire 블록 검색은 매 tick 전체 스캔이 아니라 활성 emitter 목록을 갱신하는 방식으로 처리한다.
