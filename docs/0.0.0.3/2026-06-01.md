# 2026-06-01

## 작업 기록
- `half_slab` 텍스처 기준을 긴 막대 조각이 아니라 slab을 수직으로 반 자른 조각으로 다시 맞췄다.
- 배치 좌표와 재질 좌표를 분리해 `topBottom`은 원래 slab의 위/아래면, `side`는 원래 외곽 옆면, `verticalSection`은 새 수직 절단면에만 대응하도록 수정했다.

## 작업 기록
- `half_slab` 지형 렌더링의 UV를 현재 배치 AABB 기준으로 다시 펴지 않고, 기준 `0.5 x 0.5 x 1.0` 조각의 재질 좌표를 유지하도록 수정했다.
- `half_slab`의 면 재질은 slab을 수직으로 반 자른 기준을 따른다.

## 추가 작업 기록
- `block_model` 아이템 렌더링에 `modelBlock`, `modelShape` 필드를 추가해 설치 불가 아이템도 블록 텍스처와 반블럭/1/4블럭 형태를 표시용으로 쓸 수 있게 했다.
- `half_stripped_log`, `quarter_stripped_log` 아이템을 추가하고, `stripped_log -> half`, `half -> quarter/plank`, `quarter -> long stick` 제작 흐름을 반영했다.
- pit kiln 숯화 레시피에 `half_stripped_log -> charcoal x3`, `quarter_stripped_log -> charcoal x2`를 추가했다.
- `quarter_stripped_log` 표시 형상을 반블럭의 절반 높이가 아니라 `half_stripped_log`를 수직으로 한 번 더 자른 `0.5 x 0.5 x 1.0` 조각으로 수정했다.
- 블록 텍스처 레이어에 `verticalSection`/`horizontalSection` 단면 개념을 추가하고, `stripped_log`의 수직 단면에 `stripped_log_section_vertical`을 지정했다.
- 단면 텍스처 정의는 객체형을 지원하지 않고 문자열 하나만 받도록 정리했다. 예약 면 이름이면 기존 면을 참조하고, 그 외 문자열이면 블록 텍스처 이름으로 해석한다.

## 작업 기록
- 반블럭 충돌 형상을 공용 `world` helper로 분리했다.
- 플레이어, 드랍 아이템, 파티클 지형 충돌이 `renderType = slab`과 `blockStates`의 attach 상태를 같은 AABB 기준으로 보도록 정리했다.
- 드랍 아이템의 지형 바닥/옆면 충돌과 블록 설치 시 밀어내기 판정을 AABB 기반으로 변경했다.
- 블록 파괴 파티클과 불 연기 파티클의 terrain collision callback을 AABB 기반으로 변경했다.

## 결정 사항
- 드랍 아이템과 파티클은 더 이상 충돌 블록 셀 전체를 막힌 것으로 보지 않고, 블록 충돌 형상과 대상 AABB의 교차 여부로 판정한다.
- 반블럭 충돌 형상 계산은 gameplay 전용이 아니라 world 계층에서 공유한다.

## 이슈
- 빌드는 사용자가 직접 수행한다.
- `extruded_sprite` 드랍 아이템 기본 AABB를 `0.4 x 0.05 x 0.4`로 줄였다.
- block tick을 reason 기반으로 확장하고, 블록 변화 좌표와 6방향 이웃에 self/neighbor 이벤트를 전파하도록 바꿨다.
- fire block entity에 `normal`/`pyrolysis` mode와 열분해 결과 예약 상태를 추가했다.
- fire는 주변 블록 이벤트를 받을 때만 6면 밀폐 여부를 재검사하고, `pyrolysis` 상태에서는 `charcoal`을 연료로 소비하지 않으며 열분해 불 연기 생성량은 3배로 늘린다.
- 기존 fire block entity 저장 호환은 제거하고 새 fire mode/열분해 결과 포맷을 기준으로 저장한다.
