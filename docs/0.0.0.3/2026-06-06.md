- fire block entity에 현재 타는 연료 온도인 `fireHeatLevel`을 추가하고, 저장 포맷의 기존 예약 1바이트를 이 값으로 사용하도록 했다.
- fire mode의 기본 상태를 `normal`에서 `exposed`로 바꾸고, `sealed` 구조는 `pyrolysis`, 구멍이 정확히 1개인 `vented` 구조와 `heatLevel >= 3` 연료 조합은 `firing`, 그 외는 `exposed`가 되도록 판정했다.
- fire 구조 감시 범위를 중심 `5 x 5 x 3`으로 잡고, fire에서 6방향 flood fill로 연결된 빈 공간이 AABB 껍데기 6방향 중 몇 방향에 닿는지로 leak을 계산하게 했다.
- 블록 변경 좌표가 fire의 구조 감시 범위 안에 들어가면 해당 fire를 `BlockNeighborChanged` tick에 등록하도록 해, 구조 판정을 매 연소 tick마다 반복하지 않게 했다.
- fire 작업 대상은 기존처럼 중심 같은 Y층 `3 x 3` 안에서 fire와 연결된 셀만 사용하고, 위 작업 공간은 아직 처리하지 않는다.
- 연료 선택은 fire 셀 안의 후보 중 가장 높은 `heatLevel`을 먼저 고르고, 같은 열 단계 안에서만 무작위로 고르게 바꿨다.

## 결정 사항
- 엎드림 기어오르기는 geometry를 단순 블록 높이로 추정하지 않고, 슬랩/half slab/도가니처럼 상태별 충돌 AABB를 가진 블록의 실제 top을 기준으로 한다.
- 이동 시스템은 terrain 세부 구조를 직접 알지 않고 `playerColliderTerrainClimbHeight` 콜백으로 필요한 상승 높이만 받는다.
- 왼손 `extruded_sprite`는 UV만 반전하면 원본 alpha 실루엣으로 만든 mesh와 맞지 않으므로 geometry mirror를 사용한다.
- 왼손 `block_model`은 alpha 실루엣 문제가 없으므로 기존처럼 UV mirror만 사용한다.
- 조명 감쇄는 렌더 타입별 예외보다 블록 데이터의 `lightAttenuation`을 우선한다. 현재 slab, half_slab, crucible은 모두 일반 투명 통과값 `1`로 정의한다.
- 도가니처럼 한 셀 안에 여러 cuboid가 있는 렌더 타입은 셀 내부 면에 대해 방향 이웃 조명을 사용하지 않고 현재 셀 조명을 사용한다.
- fire는 현재 연료의 `heatLevel`과 구조 폐색 단계로 모드를 정한다. 폐색 단계는 `sealed`, `vented`, `exposed` 세 단계이며, `firing`은 `vented + heatLevel 3`에서만 성립한다.
