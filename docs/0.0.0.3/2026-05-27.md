# 2026-05-27

## 작업 기록
- 드랍 아이템 상호작용 UI를 다시 우클릭 유지/해제 방식으로 변경했다.
- 후보 UI는 가장 안쪽 `Cancel` 영역, 바깥 1링 액션 영역, 그 바깥 1링 후보 아이템 영역으로 구성했다.
- 우클릭 유지 중 마우스 위치의 중심 기준 거리와 각도로 액션/후보 선택을 갱신하고, 우클릭 해제 시 선택 후보를 실행하도록 했다.
- 후보 아이템은 아이콘만 표시하고, 선택 중인 액션/후보 이름은 중앙 라벨로 표시하도록 했다.
- 액션 구역은 화면 위쪽 시작각부터 시계방향으로 나누고, 후보 아이템은 선택된 액션 구역 안에서 배치되도록 개선했다.
- 원형 상호작용 UI의 부채꼴 배경과 선택 하이라이트를 native Vulkan 렌더 패스로 분리했다.
- RmlUi는 액션 심볼, 후보 아이템 아이콘, 중앙 선택 라벨을 표시하도록 정리했다.
- 액션/후보 아이콘은 각 부채꼴 링 두께의 정중앙에 배치하도록 보정했다.
- 중앙 라벨은 선택된 액션 이름 또는 후보 아이템 이름을 표시한다.
- 원형 상호작용 UI가 열린 동안에도 `F2` 스크린샷 입력은 처리하도록 했다.
- 석기 1차 흐름에 맞춰 `stone_flake`, `stone_chopper`, `stone_blade`, `stone_scraper` 아이템 정의와 상호작용 레시피를 추가했다.
- 상호작용 레시피에 `min`/`max` 결과 개수 범위를 지원하도록 추가했다.
- `stone_shard + smash`는 `stone_flake`를 1~2개 생성하도록 했다.
- `plant + scrape`는 `plant_fiber`를 생성하도록 상호작용 레시피를 추가했다.
- 현재 구현 기준 문서로 `docs/design/item-interactions.md`를 추가했다.
- 아이템 액션을 우클릭용 `useActions`와 좌클릭 블록 파괴용 `breakActions`로 분리했다.
- 블록 정의에 `breakLevel`과 `breakAction`을 추가하고, 파괴 진행도를 도구 레벨과 파괴 동작으로 보정하도록 했다.
- 내구도 있는 아이템은 블록을 실제로 파괴할 때 내구도를 소비하도록 했다.
- `stone_shard`, `stone_chopper`, `stone_blade`에 초기 내구도 64와 파괴 액션을 부여했다.
- 핫바와 인벤토리 슬롯에 마인크래프트식 내구도 바를 추가했다.
- 플레이어 저장 슬롯과 드랍 아이템 저장 payload에 `durability`를 추가했다.
- 우클릭 드랍 아이템 상호작용 성공 시 손에 든 아이템 내구도 1을 소비하도록 했다.
- 인벤토리 아이템 툴팁 제목/세부 라인 글씨 크기를 키우고, 우클릭 액션, 파괴 액션, 파괴 레벨, 내구도 항목을 추가했다.
- 긴 디버그 항목 줄바꿈이 줄 간격과 겹치지 않도록 아이템 툴팁 최대 너비를 1000px로 키웠다.

## 결정 사항
- 드랍 아이템 상호작용 UI는 클릭 선택 방식이 아니라 우클릭 유지 중 마우스 위치 기반으로 선택한다.
- 후보 아이템은 전체 원을 다시 나누지 않고 선택된 액션 구역의 각도 범위 안에서만 선택한다.
- RmlUi는 부채꼴 같은 비정형 도형을 직접 담당하지 않고, native 렌더링은 배경/하이라이트, RmlUi는 심볼/텍스트 레이어를 담당한다.
- 아이템의 `actions`는 손에 들었을 때 수행 가능한 우클릭 작업 목록으로 두고, 실제 결과 후보는 별도 레시피에서 정의한다.
- 결과 개수가 2개 이상인 상호작용은 대상 드랍 아이템을 첫 결과로 변환하고, 나머지는 주변에 별도 드랍 아이템으로 생성한다.
- 현재 기준에서 `actions` 명칭은 `useActions`로 바꾸고, `actions`는 로더의 구버전 호환 입력으로만 허용한다.
- 블록 파괴 레벨이 부족하면 진행도와 오버레이가 생기지 않는다.
- 파괴 동작이 맞지 않아도 레벨이 충분하면 파괴 가능하지만 파워는 절반, 내구도 소비는 3으로 처리한다.
- 우클릭 상호작용은 레시피 실행이 실제로 성공했을 때만 내구도를 소비한다.
- 툴팁 레이아웃은 고정 줄 수가 아니라 실제 표시 항목 수를 기준으로 높이를 계산한다.
- 툴팁 세부 라인 폭 추정값을 20px 글꼴에 맞춰 키워 긴 디버그 줄이 불필요하게 줄바꿈되지 않도록 했다.
