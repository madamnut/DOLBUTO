- 위에서 떨어진 아이템이 아래 아이템의 top plane을 통과하면 먼저 아래 아이템 위에 착지하도록 처리했다.
- 아이템 위에 얹힌 아이템은 아래 아이템과 수평으로 충분히 겹쳐 있는 동안 지지된 상태로 유지한다.

## 결정 사항
- 아이템 데이터에는 해당 아이템을 손에 들었을 때 수행 가능한 액션만 둔다.
- 실제 후보 목록은 손 아이템의 액션과 땅에 떨어진 대상 아이템 key를 기준으로 별도 상호작용 데이터에서 찾는다.
- 초기 상호작용 후보 데이터는 `action`, `target`, `candidates`만 가진 단순 형식으로 시작한다.
- 원형 후보 UI는 RmlUi로 표시하되 액션/후보 선택 판정은 `GameClient`에서 화면 중앙 기준 거리와 각도로 계산한다.
- 현재 상호작용 실행은 손 아이템을 소모하지 않고 대상 드랍 아이템 1개를 후보 아이템으로 변환한다.
- 월드 드랍 아이템과 viewmodel 아이템은 같은 정적 item mesh buffer를 공유하되 instance buffer 쓰기 영역은 분리한다.
- 현재 실제 아이템은 모두 스택되지 않으며, 월드 드랍 엔티티 하나는 아이템 1개를 의미한다.
- 저장 payload의 `count`는 호환용으로 남기되 런타임에서는 `1`로 정규화한다.
- 드랍 아이템 렌더 회전은 시각 효과이며, 충돌체는 플레이어 콜라이더처럼 회전하지 않는 AABB로 둔다.

## 이슈
- `assets/data/interactions.json`은 현재 테스트 후보 데이터이며 후보별 레시피/성공률/부산물/도구 손상은 아직 정의하지 않았다.
- 빌드는 사용자가 직접 수행한다.
