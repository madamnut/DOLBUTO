# 2026-06-03

## 작업 기록
- 불 연기 파티클의 X/Z 수평 속도 감속을 제거했다.
- 연기 파티클이 수평 이동으로 위쪽 충돌 범위에서 벗어나면 다시 상승할 수 있도록 X/Z 이동 후 Y 이동을 처리하게 했다.
- 연기 파티클에 상승 가속과 최대 상승 속도를 적용했다.
- 연기 파티클 texture array를 normal, darker, lighter 3세트로 확장했다.
- `pyrolysis` fire는 darker smoke texture set, `firing` fire는 lighter smoke texture set을 사용하도록 했다.
- 연기 파티클 생성 위치의 X/Z 무작위 범위를 fire 중심 기준 `-0.40~0.40`으로 확장했다.
- 연기 파티클 초기 X/Z 속도 무작위 범위를 `-0.875~0.875`로 확장했다.
- 연기 파티클의 X/Z 이동량이 생성 후 2초 동안 선형으로 줄어 0이 되도록 했다.
- 블록 데이터에 `leafDecayable`, `leafDecaySupport` 속성을 추가했다.
- `leaves`는 6방향 깊이 4 안에 `log` 또는 `stripped_log` support가 없으면 block tick에서 decay되도록 했다.
- 잎 decay로 제거되는 블록도 일반 블록 파괴 흐름과 동일하게 드랍, 파티클, 편집 메쉬 갱신을 발생시키도록 했다.
- 잎 decay로 제거되는 블록은 드랍, 파티클, 편집 메쉬 갱신은 유지하되 블록 파괴 사운드는 재생하지 않도록 조정했다.
- 슬랩과 half slab은 조명 전파에서 공기처럼 감쇄 없이 통과하도록 단순화했다.
- 블록 변경 시 청크 전체 `localLight`를 즉시 재계산하지 않고 local light update queue에 변경 좌표 주변을 등록하도록 바꿨다.
- `WorldRuntime::tickLocalLightUpdates`를 추가해 셀 단위로 sky/block light 기대값을 증분 갱신하고, 바뀐 subchunk만 resolved light와 메쉬 리빌드 대상으로 넘기도록 했다.
- 유체 존재 여부 변화도 청크 전체 조명 재계산 대신 local light update queue를 사용하도록 바꿨다.
- 블록 편집 메쉬 리빌드 전에는 local light update queue를 끝까지 비워 조명 전파 중간 상태가 렌더링되지 않도록 했다.
- block tick 결과로 여러 블록이 제거되는 경우 edited mesh rebuild를 좌표 목록으로 배치 처리해 같은 tick 안에서 중복 subchunk를 반복 리메싱하지 않도록 했다.
- fire의 `pyrolysis`/`firing` 판정을 fire 중심 같은 Y층 `3 x 3` BFS 작업 공간의 leak count 기반으로 바꾸고, fire 셀은 연료, fire 셀 밖 내부 작업 셀은 processing 대상으로 분리했다.
- `processings.json`에 `outputCount`를 추가하고, `pyrolysis` 레시피와 600틱 처리 시간을 등록했다. `firing` 레시피도 600틱으로 조정했다.
- 드랍 아이템 엔티티에 `processingType`을 저장해 서로 다른 processing 진행도가 섞이지 않도록 했다.
- fire block entity의 열분해 결과 예약 필드를 제거하고, 열분해도 드랍 아이템 엔티티 processing으로 변환되도록 바꿨다.
- `clay_brick`과 `clay_pot`을 `smash`해 각각 `grog` 4개, 8개를 얻는 레시피를 추가했다.
- 파티클 렌더링에서 quad index buffer를 생성 시점에 한 번만 채우고, 매 프레임에는 재사용 scratch vertex buffer 데이터만 갱신하도록 최적화했다.
- 파티클 vertex buffer를 persistent mapping 상태로 유지해 매 프레임 `vkMapMemory`/`vkUnmapMemory`를 반복하지 않도록 했다.
