셀 배치

0은 격자 중앙, 1은 각 격자 안에서 무작위 위치입니다. 셀마다 면적과 모양이 달라집니다.
씨앗 기반 대륙 성장 서로 이웃하지 않는 셀에 씨앗을 배치합니다. 공간이 부족하면 요청보다 적게 배치되며 실제 개수를 지도 위에 표시합니다. 단계 시작 시 육지와 맞닿은 바다 셀만 성장합니다. 기존 육지는 계속 유지됩니다.
고정 성장 확률 지도 0은 모든 곳에서 기본 확률, 높일수록 잘 자라는 곳과 느린 곳의 차이가 커집니다. 지도는 매 단계 바뀌지 않습니다. 2의 지수승 블록. 기본 14 = 16,384블록입니다. 기본 12 = 4,096블록입니다. 두 굴곡은 각각 주기적 노이즈 2옥타브를 사용합니다. 기본 큰 굴곡 75% + 작은 굴곡 25%. 기본 성장 확률을 중심으로 지역별 차이를 줍니다. 기본 0%는 전부 정지, 100%는 전부 성장합니다.
접촉한 대륙은 씨앗 수 제한 없이 병합합니다. 육지를 삭제하지 않으며 원래 씨앗 수를 합산합니다. 동서·남북 끝도 연결됩니다.
전역 셀 경향 고도 경향은 바다 −1(깊음)~0, 육지 0~+1(높음)입니다. 압축은 0(약함)~1(강함)이며 실제 블록 높이·밀도 수식은 아직 적용하지 않습니다. 육지 고도와 바다 수심은 같은 마스터 시드에서 서로 다른 지역 무늬를 만듭니다. 해안 거리는 경향만 주며, 지역 변동이 이를 뒤집어 해안 옆 심해나 낮은 내륙이 생길 수 있습니다. 이웃 혼합은 같은 육해 종류끼리만 적용합니다. 간격 14는 16,384블록입니다. 전이 폭은 중심값에서 같은 종류의 경계값으로 변하는 셀 내부 비율입니다. 작을수록 경계 가까이에서 급하게 변합니다. 해안 양쪽 경향값은 별도로 유지합니다. 셀은 바이옴 경계가 아닙니다.
경계 워핑 간격 = 2의 지수승 블록. 11이면 2,048블록입니다. 주기적 노이즈로 표본 좌표를 이동해 경계를 구부립니다. 성장의 이웃 관계는 바꾸지 않습니다. 강도가 크면 같은 셀이 여러 조각으로 보일 수 있습니다.
표시 경계 0블록은 검정, 지정 거리 이상은 흰색입니다. 워핑 전 실제 경계 선분까지의 최단거리이며 높이 값이 아닙니다. 육지·바다 중 한 종류만 있으면 경계 없음으로 표시합니다. 생성점은 흰 점으로 표시합니다.

마우스 위치를 중심으로 휠 확대 · 드래그하는 동안 즉시 이동 · 클릭으로 셀 선택. 자동 미리보기를 켜면 조작이 끝난 뒤 새 범위를 계산합니다. 계산되지 않은 부분은 어둡게 표시합니다.

설정 저장을 누르면 배치·표시 범위·해상도를 저장하고 다음 실행 때 복원합니다. 마스터 시드는 기후 작업과 함께 보관합니다. 게임 기본값은 기후 편집기에서 직접 확정 저장해야 합니다.
